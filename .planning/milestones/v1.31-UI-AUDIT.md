## Top-line verdict

The surface is **brand-coherent and structurally sound** (dark "signal-line" identity, Find/Verify/Prove triad, GDS-tone Home, strong Row-history pattern). The "less-iterated" hypothesis is **confirmed**: the Prove-cluster ops screens (Exports, Retention) and the Find-detail screens (Transaction, Actor) lag Home/Timeline. The two highest-leverage problems are systemic, not cosmetic:

1. **The status/verdict color + badge contract is broken** — one concept renders in different colors and **four** different badge treatments across screens, backed by two unrelated CSS families. Fixing this in Phase 136 is the prerequisite that makes every per-screen polish pass coherent.
2. **Seed data undersells the product** — `Actor unknown` on virtually every row, ~95% INSERT (UPDATE/DELETE color system never appears), empty transaction diffs, no saved views. The UI can't demo its core value. Phase 135 unblocks honest screenshots for all later phases.

## Findings — cross-cutting / design system (Phase 136, highest leverage)

| ID | Sev | Finding | Proposed resolution |
|----|:--:|---------|---------------------|
| F-101 | HIGH | **One status vocabulary, four renderings.** Queued/Completed/Failed = outline-pill-as-header (Exports), outline-pill-in-cell + redundant row stripe (Retention), filled-soft pill (Redaction); two unrelated CSS families `.tl-chip--*` (24px, pill) vs `.tl-badge`/`.tl-change__op` (22px). | Single `.tl-status-badge` keyed off a status enum; deprecate ad-hoc per-screen pills. Drop double-encoding (stripe **or** badge, not both). |
| F-102 | HIGH | **Verdict color contract inconsistent.** "Uncovered" = amber in Coverage header badge but red in the Coverage table; `inferred_posture` = `tl-chip--info` = **the same Thread Blue as links/actions**, so the verdict collides with buttons. Source: `presentation.ex:71` `status_modifier/1`, `surface_header.ex:64`. | Lock `proven/inferred/unsupported` and `covered/uncovered/expected-gap` to one non-interactive color scale; give `inferred` a distinct (Signal-Cyan-outline or muted) treatment that never reads as a link. |
| F-103 | HIGH | **op-color is not a shared primitive.** `op_chip_modifier` is applied in `transaction_live.ex:159` but NOT in `row_history_component.ex:100` — so INSERT/UPDATE both render blue in the as-of drawer. | Apply the shared op-chip modifier everywhere op badges appear (drawer timeline, actor rows). |
| F-104 | HIGH | **Two value/KV rendering systems.** Transaction diffs use `tl-change__before/after`; Row history uses a separate `tl-kv`; Actor rows use neither. Same data (column→value) rendered three ways. | Factor one shared mono value / KV / diff primitive so snapshots and diffs read identically. |
| F-105 | MED | **Chip roles undifferentiated.** Toggle (Exports "Actor-owned jobs"), status-assertion (Redaction "Drift blocks trust"), verdict-filter, and cross-screen nav links all render as one undifferentiated chip row. | Define distinct chip roles (toggle vs assertion vs verdict vs nav-link) as named primitives; apply the IA "subtle divider before Exports" instinct to the Evidence proof-rail too. |
| F-106 | MED | **Card-accent rule undocumented.** The cyan signal-line top accent appears only on Home's FIND card, implying "only Find is live." Three cards, three button treatments. | Codify when the signal-line accent and primary-button-per-card apply; standardize control affordance across cards. |
| F-107 | MED | **Radius/scale drift.** Pill chips (`--tl-radius-pill`) next to more-rectangular outline buttons (`--tl-radius-md`) inside `--tl-radius-lg` cards read inconsistent in one viewport. | Confirm intended radius per primitive; consider md chips inside cards. |
| F-108 | MED | **Native `datetime-local` breaks dark-first.** The as-of control (`row_history_component.ex:92`) and Timeline from/to render OS light calendar chrome; on the canonical as-of surface Signal Cyan (the as-of/signature signal) is entirely absent. | Dark-skin the date controls; lean on Signal Cyan for the as-of axis. |
| F-109 | LOW | **Count echo.** Coverage shows "12 need capture" up to 4× above the fold (header badge / pill / metric card / callout); Timeline duplicates it as a stat + chip. | Pick one owner per surface; cross-link rather than restate. |
