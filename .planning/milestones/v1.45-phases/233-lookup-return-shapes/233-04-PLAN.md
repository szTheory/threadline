## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host authorize_fn -> scope value | the host decides tenancy; Threadline must apply it or refuse |
| host scope_query_fn -> every scoped SQL read | a missing or mis-wired function decides whether tenants are isolated |
| ArgumentError text -> logs / error pages | misconfiguration errors are operator-visible |
