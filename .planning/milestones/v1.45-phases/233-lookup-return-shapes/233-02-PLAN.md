## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-233-05 | Information disclosure | TransactionLookup.fetch/2 changes read | high | mitigate | changes scoped with hardcoded :transaction surface; the row is only reused after it passed the :transaction_header scope; scope-rejects-row parity test across all three lookups |
| T-233-06 | Information disclosure | caller-supplied :surface/:params | high | mitigate | allowlist rejects :surface/:params so a caller cannot relabel a binding shape and fall into a permissive scope-fn clause (tests per function) |
