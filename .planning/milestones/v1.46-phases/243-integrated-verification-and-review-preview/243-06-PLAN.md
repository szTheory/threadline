| Boundary | Description |
|---|---|
| Local candidate to remote required CI | Only the maintainer-authorized pushed SHA can establish live required-run evidence. |
| Remote workflow artifact to local review | Downloaded PR-controlled receipt is untrusted data; validate schema, identity, hashes and safe fields before indexing. |
| Index to release recommendation | An evidence gap or stale candidate cannot be described as release-ready. |
