## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser filter data to Timeline | Keys and values are untrusted; host scope remains server-owned. |
| Current ActorRef to SavedView | Search identity and filters cross actor-owned persistence. |
| Search URL to receiving host | Definition is parsed again and reauthorized under recipient scope. |

## Applicable ASVS Level 1 Controls

| Control | Planned mitigation |
|---|---|
| V4 Access Control | Scope SavedView reads/mutations to current ActorRef and reauthorize receiving-host queries. |
| V5 Input Validation | Reuse FilterParams allowlist and canonicalizer; ignore unsupported URL fields. |
| V7 Error Handling | Keep saved-search failures actionable and never report failed operations as complete. |
| V8 Data Protection | Share only supported applied filter definitions; exclude scope, tenant, cursor, drafts, and saved-record data. |
