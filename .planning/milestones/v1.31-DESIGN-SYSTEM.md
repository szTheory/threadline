# v1.31 Design System Catalog

This catalog is the source-first design-system freeze for the Threadline operator surface. The contract is the Phoenix-optional CSS emitted by `Threadline.OperatorSurface.Style`, scoped under `.threadline-ui`, and the source tests in `style_contract_test.exs`. It does not create a public component library API.

## Source Of Truth

The source of truth is `lib/threadline/operator_surface/style.ex`; the freeze is guarded by `test/threadline/operator_surface/style_contract_test.exs`.

Maintainers should treat the `--tl-*` tokens and canonical `.tl-*` families below as the allowed operator-surface vocabulary. Documentation follows source. If a future change updates a token, primitive, or anti-pattern rule, update source and the narrow source contract first, then update this catalog.

## Action Hierarchy

Every operator surface should expose one clear primary action slot, then secondary and ghost actions. Primary actions use `.tl-button--primary`; secondary navigation or less urgent actions use `.tl-button--secondary`; low-emphasis utility actions use `.tl-button--ghost`; destructive actions use `.tl-button--danger` and must include context before the control.

Button states are part of the freeze: hover, active, disabled, busy, and ARIA-disabled states are token-backed. Disabled controls must not rely on opacity alone.

## Empty And Error States

Use `.tl-empty` for diagnostic absence and `.tl-alert--error` or `.tl-empty--error` for recoverable failures.

Empty states must explain whether the cause is filters, time window, missing setup, unsupported feature, or genuinely no history. Error states must pair the problem with a recovery path, such as rerunning a style contract test, widening a filter, or checking a CLI/API command where the screen owns setup.

## Tables And Responsive Rules

The surface is mobile-first. Base responsive tables stack into labelled cards with `.tl-table--responsive`, hide `<thead>`, and use `td::before { content: attr(data-label); }`. The tablet layer starts at `768px` and preserves labelled card tables. The desktop dense/operator layer starts at `1280px` and restores table semantics with `display: table`, `table-row-group`, `table-row`, and `table-cell`.

Do not hide root overflow to mask layout bugs. Long IDs, refs, and values use `min-width: 0`, `overflow-wrap: anywhere`, mono text, and copy affordances.

## Copy Affordances

Use `.tl-copy` for copyable refs, IDs, and operator evidence handles. It is a secondary affordance, never a greyed-out disabled-looking control. The `.tl-copy.is-copied` state uses Signal Cyan border/text and a static "Copied" chip so confirmation remains visible when reduced motion collapses animations.

## Drawer And Subview Patterns

Use `.tl-subview-backdrop` and `.tl-subview` for row history and detail drawers. Drawers are dark-first raised surfaces, width-capped by `--tl-drawer-width` at desktop, full viewport on mobile, and covered by `role="dialog"` focus styling. Subview content uses `.tl-subview__header`, `.tl-subview__title`, `.tl-subview__content`, and `.tl-subview__timeline`.

Drawer motion is `tl-drawer-in` with `--tl-motion-base` and `--tl-ease-standard`; reduced motion collapses it.

## Motion

Motion is purposeful, source-inventoried, and token-backed. The locked keyframes are `tl-drawer-in`, `tl-rise-in`, `tl-thread-draw`, `tl-fade-in`, and `tl-copy-pulse`.

Use `--tl-transition-fast` for frequent hover/focus state changes; use mount animations only for low-frequency evidence assembly, drawer entry, copy success, or signature proof/progression lines. Do not use `transition: all`. Do not introduce animation libraries. Reduced motion is centralized in `@media (prefers-reduced-motion: reduce)` and collapses transitions/animations to `1ms`, resets delays, keeps a single iteration, uses `scroll-behavior: auto`, and removes active button transform.

## Focus And Accessibility

The operator surface is dark-first and must preserve accessible contrast. `style_contract_test.exs` checks dark-surface contrast for text, muted, semantic, danger, accent, and status colors against dark backgrounds.

Focus uses `--tl-focus-ring` and `:focus-visible` selectors for buttons, role buttons, inputs, selects, links, and summaries. The source forbids blanket outline removal. Status and verdict UI must include readable text, border/background treatment, and non-color labels. Use ARIA state hooks such as `aria-current`, `aria-pressed`, `aria-disabled`, and `role="dialog"` where the source already treats them as styling and accessibility contracts.

## Copy Voice And JTBD Anchors

Threadline copy should help operators "follow what happened" without guessing the underlying schema. P1 needs fast attribution from correlation or record context; P2 needs plain-language record history and copy/export affordances; P3 needs defensible proof and handoff; P4 needs health and completeness signals; P5 needs setup diagnostics.

This catalog explains existing and frozen primitives only. It does not add new flows. Earned-flow IDs EF1-EF5 remain governed by the v1.31 personas/IA artifact and the phases that already shipped them.

## Anti-Patterns

The design system explicitly forbids:

- Tailwind or `@tailwind`.
- Any new CSS build step.
- Light theme, system theme, `prefers-color-scheme`, or `color-scheme: light`.
- Any theme toggle or `theme-toggle` behavior.
- Any external design-system dependency, including shadcn, daisyui, Heroicons, CSS-in-JS, or animation libraries.
- A public Phoenix component library API for these primitives in v1.31.
- Unscoped global CSS outside `.threadline-ui`.
- `transition: all`.
- Status or verdict UI that relies on color alone.
