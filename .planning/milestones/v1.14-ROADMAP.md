# Milestone v1.14: Drop-in Production Adopter Slice

**Status:** ✅ SHIPPED 2026-05-05

## Overview

This milestone made Threadline materially easier to adopt in production by shipping an optional Sigra integration adapter, a reproducible benchmark harness with published baselines, an operator incident playbook plus replay tooling, a SaaS quickstart, and the `0.3.0` release packaging surface.

## Milestone Summary

**Key Decisions:**

- Keep Sigra as an optional host integration rather than a library dependency.
- Isolate benchmarking into a sibling Mix project and keep `verify.bench` out of normal PR CI.
- Treat release verification as a clean-tree gate and validate it in an isolated worktree when the main workspace is intentionally dirty.

**Issues Resolved:**

- Closed the actor-mapping adoption gap for Sigra-backed Phoenix applications.
- Repaired the benchmark publication chain so baselines land in tracked artifacts and docs.
- Aligned the incident and adopter guides with the shipped API surface and release packaging.
