```elixir
defmodule Threadline.Integrations.Sigra do
  @moduledoc """
  Adapter mapping Sigra-aware Phoenix conns to Threadline `ActorRef` and
  `correlation_id` overrides.

  This module is the wiring point between a Phoenix host running
  [Sigra](https://hex.pm/packages/sigra) and `Threadline.Plug`'s `:actor_fn`
  callback. It is safe to load when `:sigra` is not installed — every public
  function gates on `Code.ensure_loaded?(Sigra.Session)` and returns the
  Sigra-absent default (`nil` or `%{}`).

  See `guides/integrations/sigra.md` for the wiring contract.

  ## Usage

      plug Threadline.Plug, actor_fn: &Threadline.Integrations.Sigra.actor_ref_from_conn/1
  """

  alias Threadline.Semantics.ActorRef

  @doc """
  Returns an `ActorRef.t()` derived from the conn's Sigra state, or `nil`.

  Detection order (per CONTEXT D-08):

  1. `current_scope.impersonating_from` non-nil → `:admin` (real admin id)
  2. `current_scope.user` non-nil → `:user`
  3. `current_scope.auth_method` in `[:api_token, :jwt]` → `:service_account`
  4. Otherwise → `nil` (anonymous / Sigra absent / scope missing)

  Returns `nil` when `:sigra` is not installed.
  """
  @spec actor_ref_from_conn(Plug.Conn.t()) :: ActorRef.t() | nil
  def actor_ref_from_conn(conn) do
    if Code.ensure_loaded?(Sigra.Session) do
      do_actor_ref(conn)
    else
      nil
    end
  end

  @doc """
  Returns a map of `Threadline.Semantics.AuditContext` field overrides derived
  from Sigra state. Currently produces only `:correlation_id`.

  When the conn carries an `x-correlation-id` request header, returns `%{}` —
  explicit integrator intent always wins (Q3 / SPEC requirement 7).

  When the header is absent, builds correlation_id per these formats:

    * impersonation: `"sigra-imp:<session_id>:user:<imp_user_id>"`
    * plain session: `"sigra-session:<session_id>"`
    * API token:     `"sigra-token:<token_id>"`
    * anonymous:     no override (`%{}`)

  Each format optionally has a `:org:<org_id>` suffix when
  `current_scope.active_organization_id` (or session.active_organization_id) is
  non-nil.

  Returns `%{}` when `:sigra` is not installed.
  """
  @spec audit_context_overrides_from_conn(Plug.Conn.t()) :: %{optional(:correlation_id) => String.t()}
  def audit_context_overrides_from_conn(conn) do
    if Code.ensure_loaded?(Sigra.Session) do
      do_overrides(conn)
    else
      %{}
    end
  end

  @doc """
  Returns `&actor_ref_from_conn/1` as a captured function reference suitable
  for `Threadline.Plug`'s `:actor_fn` option.

  This is a factory — the result is a function, not an `ActorRef`.

      plug Threadline.Plug, actor_fn: Threadline.Integrations.Sigra.actor_fn()
      # equivalent to:
      plug Threadline.Plug, actor_fn: &Threadline.Integrations.Sigra.actor_ref_from_conn/1
  """
  @spec actor_fn() :: (Plug.Conn.t() -> ActorRef.t() | nil)
  def actor_fn, do: &actor_ref_from_conn/1

  # ----- private -----

  defp do_actor_ref(conn) do
    scope = Map.get(conn.assigns, :current_scope)

    cond do
      is_map(scope) and Map.get(scope, :impersonating_from) ->
        from = Map.get(scope, :impersonating_from)
        wrap(ActorRef.new(:admin, get_id(from)))

      is_map(scope) and Map.get(scope, :user) ->
        wrap(ActorRef.new(:user, get_id(Map.get(scope, :user))))

      is_map(scope) and Map.get(scope, :auth_method) in [:api_token, :jwt] ->
        wrap(ActorRef.new(:service_account, Map.get(scope, :id)))

      true ->
        nil
    end
  end

  defp do_overrides(conn) do
    case Plug.Conn.get_req_header(conn, "x-correlation-id") do
      [_ | _] ->
        %{}

      [] ->
        scope = Map.get(conn.assigns, :current_scope)
        sigra_session = Map.get(conn.private, :sigra_session)
        build_correlation_id(scope, sigra_session)
    end
  end

  defp build_correlation_id(scope, sigra_session) do
    cond do
      is_map(scope) and Map.get(scope, :impersonating_from) ->
        sid = session_id(sigra_session)
        # NOTE: Q1 encodes the IMPERSONATED user id (the target), not the admin.
        # The admin id is captured by ActorRef in actor_ref_from_conn/1. Here we
        # encode the user being acted upon. SPEC Requirement 3 + 7 are explicit:
        # "sigra-imp:<sid>:user:<imp_user_id>" where imp_user_id is the user
        # being impersonated (the target). Re-read the user-id field via
        # Map.get on the user map.
        target_user_id = get_id(Map.get(scope, :user))
        # If `target_user_id` is missing during impersonation, the format degrades
        # to `sigra-imp:<sid>:user:` — degenerate but honest. Never silently
        # substitute the admin id (Q1 invariant).
        cid = "sigra-imp:#{sid}:user:#{target_user_id}"
        with_org(%{correlation_id: cid}, scope, sigra_session)

      is_map(scope) and Map.get(scope, :user) ->
        sid = session_id(sigra_session)
        cid = "sigra-session:#{sid}"
        with_org(%{correlation_id: cid}, scope, sigra_session)

      is_map(scope) and Map.get(scope, :auth_method) in [:api_token, :jwt] ->
        token_id = Map.get(scope, :token_id) || Map.get(scope, :id)
        cid = "sigra-token:#{token_id}"
        with_org(%{correlation_id: cid}, scope, sigra_session)

      true ->
        %{}
    end
  end

  defp with_org(%{correlation_id: cid} = overrides, scope, sigra_session) do
    org_id =
      (is_map(scope) && Map.get(scope, :active_organization_id)) ||
        org_from_active(Map.get(scope || %{}, :active_organization)) ||
        (is_map(sigra_session) && Map.get(sigra_session, :active_organization_id))

    if org_id do
      %{overrides | correlation_id: cid <> ":org:#{org_id}"}
    else
      overrides
    end
  end

  defp org_from_active(nil), do: nil
  defp org_from_active(active) when is_map(active), do: Map.get(active, :id)
  defp org_from_active(_), do: nil

  defp session_id(%{id: id}) when not is_nil(id), do: id
  defp session_id(map) when is_map(map), do: Map.get(map, :id)
  defp session_id(_), do: nil

  defp get_id(%{id: id}), do: id
  defp get_id(map) when is_map(map), do: Map.get(map, :id)
  defp get_id(_), do: nil

  defp wrap({:ok, ref}), do: ref
  defp wrap({:error, _}), do: nil
end
```

Mandatory implementation rules (drawn from RESEARCH landmines + CONTEXT decisions):
1. **Single soft-dep gate** (D-04 + RESEARCH Pattern 1): `Code.ensure_loaded?(Sigra.Session)` is the ONLY gate. NEVER `Code.ensure_loaded?(Sigra.Scope)` (host-generated, doesn't exist) or `Code.ensure_loaded?(Sigra.APIToken)` (no `defstruct` in v0.2.5 per RESEARCH Landmine #2).
2. **No Sigra alias** (PATTERNS line 33): do NOT write `alias Sigra.Session` or any other Sigra alias — use fully-qualified module names only. Aliasing forces compile-time resolution and breaks the soft-dep contract.
3. **Map.get/3 everywhere** (D-09 + RESEARCH Landmine #2): every read from `current_scope` and `sigra_session` MUST use `Map.get/3`. NEVER use dot-access on the scope map (e.g., reading the `:user` field of `current_scope` via dot-notation) — host scopes (e.g. `MyApp.Auth.Scope`) may omit optional fields and dot-access raises `KeyError`.
4. **API-token detection via auth_method** (RESEARCH Landmine #1): detect via `Map.get(scope, :auth_method) in [:api_token, :jwt]`. Do NOT read `conn.assigns[:current_api_token]` (no such assign in Sigra v0.2.5; SPEC line 41 is incorrect). The user_id for the service_account ActorRef is `Map.get(scope, :id)` (FetchBearer's `build_scope/3` calls `scope_module.new(%{id: user_id, ...})`).
5. **Mirror, never delegate** (RESEARCH Landmine #3): `Sigra.Audit.scope_fields/1` and `Sigra.Impersonation.actor_id/1` are `defp` (private). Reproduce the logic locally; do NOT call them.
6. **Always use `ActorRef.new/2`** (PATTERNS shared pattern): NEVER write a direct `%ActorRef{type: ..., id: ...}` literal. Wrap every `ActorRef.new/2` call in `wrap/1` (returns ref on `{:ok, _}` or `nil` on `{:error, _}`).
7. **Never construct `:anonymous`** (Q6 / SPEC Req 6 / SPEC Acceptance): the adapter never returns `ActorRef.new(:anonymous, nil)` — always raw `nil` for missing scope. `grep ':anonymous' lib/threadline/integrations/sigra.ex` MUST return zero matches.
