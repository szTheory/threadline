# Requirements: Threadline v1.33 Brand Review + Direction Selection

**Defined:** 2026-06-05
**Core Value:** Every row mutation that matters is captured durably and linked to who did it and why - without the developer having to remember to opt in.

## v1.33 Requirements

### Human Brand Review

- [x] **REVIEW-PACKET-01**: User can inspect the existing `brandbook/` HTML, logo assets, visual specimens, token files, and copy guidance through a concise review packet before any public rollout is selected. Completed in Phase 150.
- [x] **REVIEW-DECISION-01**: User can choose whether the current brand direction is accepted, needs targeted revisions, needs alternate concepts, or should be deferred before rollout work starts. Completed in Phase 151; targeted revisions selected.

### README/GitHub Readiness

- [x] **README-FIT-01**: Review evaluates the brand direction against README/GitHub as the primary deciding surface rather than a generic marketing-site standard. Completed in Phase 150.
- [x] **LOGO-LIGHT-01**: The logo system includes a primary light-background lockup for README/GitHub/light docs so the dark-surface primary logo is not forced onto white backgrounds. Completed in Phase 150.

### Targeted Revisions And QA

- [x] **REVISION-01**: Any approved changes are limited to material issues in logo legibility, favicon clarity, README/GitHub fit, social-card balance, copy specificity, token consistency, or accessibility. Completed in Phase 152 through stand-alone brandbook truth cleanup.
- [x] **BRAND-QA-02**: Final review or revision pass verifies JSON parsing, SVG parsing, direct-open HTML rendering, desktop/mobile screenshots, file-type boundaries, and file-size discipline after the last change. Completed in Phase 153.

## Future Requirements

### Public Rollout

- **README-ROLLOUT-01**: Apply the approved brand voice and selected assets to the public root README with doc-contract coverage.
- **HEXDOCS-BRAND-01**: Evaluate whether ExDoc should receive restrained brand treatment after docs IA is stable.
- **LANDING-01**: Build a public landing page only after the brand direction is approved and a separate information-architecture/content scope is selected.

## Out of Scope

| Feature | Reason |
|---------|--------|
| Full brand-system redo | The current v1.32 brandbook is directionally strong; this milestone exists to review and target-fix, not churn. |
| Runtime operator surface UI changes | v1.31 froze the operator surface design contract; review must not mutate product UI. |
| README/HexDocs/marketing-site rollout | This milestone selects and verifies direction first; rollout requires separate requirements and public-surface QA. |
| Large raster exports or PDF batches | Brand artifacts stay text/SVG/HTML/CSS/JSON-first; screenshots remain temporary review evidence unless a downstream channel requires export. |
| Legal/trademark clearance | Human/legal review remains outside GSD automation. |
