## Shared procedure (Plans 06 and 07)

Record the plan base first (Task 1 step 0): `git rev-parse HEAD > "$(git rev-parse --git-dir)/gsd-203-NN-base"` with this plan's number, and copy the SHA into the SUMMARY. The file lives in the git dir, so it is never staged.

Measure with `ASDF_ERLANG_VERSION=27.3 ASDF_ELIXIR_VERSION=1.17.3-otp-27 sh -c 'mix compile >/dev/null 2>&1; mix credo --strict --config-file deps/credo/.credo.exs --format json' | jq -r '.issues[] | select(.check != "Credo.Check.Refactor.Nesting" and .check != "Credo.Check.Refactor.CyclomaticComplexity") | "\(.filename):\(.line_no) \(.check)"'`. Line numbers moved in Plans 01-05, so always use this live output and never the RESEARCH line numbers.

**Read scope (context budget):** read each flagged line with enough surrounding context to see the whole construct being changed (the enclosing `with`/`cond`/`try`/pipeline), located with Read offset/limit. Never read a long file whole.

Fix forms:
- **MapJoin:** `Enum.map_join/3`.
- **FilterFilter / RejectReject:** merge the predicates into one pass.
- **ExpensiveEmptyEnumCheck:** `Enum.empty?/1` or `== []`.
- **NegatedConditionsWithElse:** swap the branches.
- **UnlessWithElse:** `if` with the branches swapped.
- **CondStatements:** a two-branch cond becomes `if`.
- **PreferImplicitTry:** drop the explicit `try` for the function-level implicit form.
- **RedundantWithClauseResult:** return the last clause's expression directly.
- **WithSingleClause:** `case`. Choose a form that does not add a nesting level.
- **ParenthesesOnZeroArityDefs:** drop the `()`.
- **MaxLineLength:** break the line.
- **AliasOrder:** reorder.

After each file, run `mix compile --warnings-as-errors` and that file's tests. Commit template: `refactor(203-NN): resolve <Check[, Check]> findings in <path-or-dir>`. Body: "Mechanical Credo sweep: <checks>. No behavior change. Verified: <commands>."
