## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Caller repository → disposable clone | Only committed state may enter the certification target. |
| Clone `.planning` → sibling quarantine | Restoration must precede any recursive cleanup on every exit. |

| Source tree → planning-dependency scanner | A hidden planning read could make the aggregate pass only in the developer checkout. |
