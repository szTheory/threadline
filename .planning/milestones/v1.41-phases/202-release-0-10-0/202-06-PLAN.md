<objective>
Close born-red cause BR-3: `mix dialyzer` fails with one `unknown_function` error because
`lib/mix/tasks/release.pins.ex:103` calls `Threadline.MixProject.project/0`.

Purpose: `MixProject` is defined in `mix.exs`, which Mix evaluates but never compiles into
`_build/dev/lib/threadline/ebin`. Dialyzer analyses ebin, so the function genuinely does not
exist in the analysed set. The call works at runtime — this is not a latent crash — but it fails
a gate that `ci.all` treats as blocking, and it was introduced by this phase's own Plan 202-02.

Output: `mix dialyzer` green, with the runtime-read property the original code was defending
still intact.
</objective>
