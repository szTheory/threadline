<objective>
Close born-red cause BR-5: `test/threadline/release_artifact_contract_test.exs:345` asserts a
hardcoded literal `{:threadline, "~> 0.9.0"}`.

Purpose: Phase 202 designated `mix release.pins` the single writer of every documented install
pin, precisely so no version string is maintained by hand. This test hardcodes the value that
task exists to change. The moment the sole writer does its job and rewrites README to
`~> 0.10.0`, this contract goes red — so the release is born red by construction, which is the
exact structural shape RELEASE-BLOCKERS.md describes.

Output: a contract that verifies the pin is correct rather than that it is a particular string,
and which therefore survives every future bump without being edited.
</objective>
