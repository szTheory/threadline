# Milestone v1.15: Host Integration Completion

**Status:** ✅ SHIPPED 2026-05-05
**Phases:** 49-52
**Total Plans:** 8

## Overview

This milestone closed the remaining Phoenix host-integration seams by making `Threadline.Plug` own additive request metadata overrides, establishing direct Sigra callback wiring as the canonical host pattern, securing the incident drill-down reference path behind an authenticated baseline, and aligning every adopter-facing doc plus contract suite around that story.

## Phases

### Phase 49: Native Plug Context Overrides

**Goal**: Make additive request-context wiring a first-class `Threadline.Plug` capability instead of an example-only plug composition pattern.
**Depends on**: Phase 48
**Requirements**: PLUG-01, PLUG-02
**Plans**: 2 plans

Plans:

- [x] 49-01: Tighten `Threadline.Plug` override authority, precedence, and tests around the in-flight implementation
- [x] 49-02: Align Sigra/quickstart docs and doc-contract tests with the narrowed override contract

**Details:**

- Added native `:context_overrides_fn` support to `Threadline.Plug` with additive-only semantics for `request_id` and `correlation_id`.
- Kept actor authority on `actor_fn` and transport authority on existing header/conn-derived values.
- Locked the narrowed contract in focused code tests and adopter-facing doc-contract suites.

### Phase 50: Direct Sigra Host Wiring

**Depends on**: Phase 49

- [x] 50-02: Align the canonical Sigra docs and drift guards

**Details:**

### Phase 51: Authenticated Incident Drill-down

**Goal**: Turn the incident JSON drill-down path into a host-safe reference pattern by adding a clear authentication boundary and documenting what remains host-owned.

## Milestone Summary

**Key Decisions:**

- Keep `actor_fn` as the sole actor-authority seam and limit `context_overrides_fn` to additive request metadata only.
- Teach direct Sigra callback wiring in the example app and docs instead of preserving example-local helper seams.
- Make the example incident drill-down path authenticated by default while leaving tenancy and richer authorization in host scope.

**Issues Resolved:**

- Closed the last host-wiring gap between the shipped library surface and the Phoenix example app.
- Replaced the old example-only Sigra composition seam with the actual public callback contract.
- Aligned the adopter-facing docs and tests so the incident boundary and host-owned authorization story no longer drift independently.

**Issues Deferred:**

- The open-artifact audit still reports `SEED-001-sigra-integration-adapter`, but the seed had already been promoted into v1.14 and is stale bookkeeping rather than open scope.

**Technical Debt Incurred:**

- No blocking technical debt remains for the milestone definition of done; the missing Phase 52 validation artifact was backfilled during closeout.
