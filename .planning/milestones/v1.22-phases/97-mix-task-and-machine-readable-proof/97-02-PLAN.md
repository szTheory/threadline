| Boundary | Description |
|----------|-------------|
| Evidence facts -> semantic verdict | Misclassifying host-owned or unsupported territory as proven would overstate Threadline’s authority. |
| Proof library -> CLI output | The task must preserve the same verdict semantics in both JSON and human-readable views. |
| Shipped code -> docs/tests | Contract docs and tests must describe the actual shipped verdict vocabulary and wrapper fields. |

| T-97-05 | Repudiation | unsupported claims | mitigate | Emit explicit `unsupported` payloads instead of omitting fields or crashing. |
| T-97-06 | Tampering | docs/task contract drift | mitigate | Lock exact verdict strings and wrapper fields in tests and reflect the shipped contract in `guides/domain-reference.md`. |
</threat_model>
