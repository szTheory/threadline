<objective>
Fix the capture down path (CAPT-01) and pin the two-migration repro with a deterministic regression
test against real Postgres (CAPT-02, deterministic half). Implements D-01..D-05, D-08, D-09 and D-12.

Purpose: an adopter who rolls back a whole `gen.triggers` chain, including a rerun that added a
per-table capture function, must be left with a clean `pg_proc`. Today the first-run `down` only
drops the per-table function if that first run needed one, so a default-then-per-table chain orphans
the function.

Output: the one-line generator change plus its comment and moduledoc, a structural orphan helper in
`MigrationHarness`, a new `describe` block in `trigger_rerun_test.exs`, updated expected-output
assertions, and a regenerated example shape fixture.
</objective>
