<objective>
Partition the CI test step (SUITE-02): a committed fail-closed runner, `bin/ci-test-partitions`,
called by CI and a new `mix verify.test_partitioned` alias, running N concurrent `mix test
--partitions N` processes in each `verify-test` lane, each on its own database (D-01..D-09), with a
runtime and a shape mutation control (D-10), Flake Detection re-derived (D-11), all landing as one
commit (D-12).

Purpose: the test step is about 4.5-4.9 minutes per lane (run 36730596489) and mostly serial; running
it as concurrent partitions inside the same job is the cheapest way to cut it at least 30% without
paying per-job setup again.
Output: the gate commit, local evidence that it is green and fails closed.
</objective>
