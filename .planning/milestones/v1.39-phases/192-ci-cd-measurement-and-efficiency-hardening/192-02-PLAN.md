## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cache restore -> build/test steps | Restored artifacts feed the gate; stale/incompatible restore could mask a failing gate |
| service image tag -> pooler behavior | A mutable `:latest` tag can drift under the topology gate |
| matrix rename -> branch protection | Renamed required checks can block merges if protection is not reconfigured (handled in Plan 04) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-192-01 | Tampering | Cache poisoning / stale-artifact bleed across lanes or MIX_ENV | high | mitigate | Cache `deps/` (source only) never `_build` (D-06/10); both lanes fetch byte-identical source from the same committed `mix.lock`; `mix deps.get` reconciles after a partial `restore-keys` hit |
| T-192-05 | Tampering | Nested-subtree cache key bleed | medium | mitigate | Playwright/npm caches keyed to `e2e/package-lock.json`, never folded into the root `mix.lock` key (D-09) |
| T-192-02 | Tampering | Supply-chain image drift (`edoburu/pgbouncer:latest`) | medium | mitigate | Pin to `edoburu/pgbouncer:v1.25.2-p0` (D-22); Plan 04 contract test asserts no `:latest` in any workflow |
| T-192-03 | Elevation of Privilege | Gate-weakening / warning-masking regression | high | mitigate | No `_build` cache; `mix deps.get`/`npm ci`/`playwright install` still run (D-12); min lane keeps `--warnings-as-errors` + full `mix test`; heavier steps gated to current only (D-18), never removed |
