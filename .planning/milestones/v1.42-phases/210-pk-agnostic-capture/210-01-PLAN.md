<objective>
Replace the hardcoded `id` extraction in all four capture-function bodies with one shared, catalog-free row-key fragment that reads trigger arguments, and install every trigger through a migrate-time DO block that resolves the table's real primary key from `pg_index` and passes its columns as trigger arguments. Proven end to end on real PostgreSQL for non-`id`, uuid, text, bigint, composite and INCLUDE-column keys (CAP-01, CAP-02; the static half of CAP-06; D-01, D-05, D-06, D-08, D-09, D-10).

Purpose: this is the one-way core of the phase. The function body and the DO-block shape are frozen into adopters' migrations; every later plan in this phase builds on them (legacy proof, refusals, override, benchmark).
Output: `Threadline.Capture.PrimaryKeySQL`, rewritten renderers and `create_trigger/3`, global function refresh in `gen.triggers`, `trigger_pk_shapes_test.exs`, `trigger_body_invariants_test.exs`.

Deliberate intermediate state (closed by plan 03 of this phase, before any release): a table with no primary key gets a trigger with no arguments from this plan's DO block (the legacy branch then applies). Plan 03 turns that into a migrate-time refusal.
</objective>
