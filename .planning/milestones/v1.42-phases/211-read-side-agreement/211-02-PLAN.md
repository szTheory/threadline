The detector fired (a pluralization cue in the ROADMAP depends-on prose). The real shift is that a row's identity goes from one scalar `id` to a set of key columns.
- **Primary noun:** the row key, an ordered set of `{field, column, value}` rendered to one jsonb map.
- **Decision: promote.** Internally, RowKey always produces the full key map, even for single-column tables. A scalar argument is accepted sugar that normalizes into that map. It is not a parallel code path.
- **Invariant test (accepted):** the type round-trip matrix in Task 3 is the invariant: every supported key shape round-trips capture → history. It goes red if a later change reintroduces a scalar-only assumption.
</assumption_delta_decision>
