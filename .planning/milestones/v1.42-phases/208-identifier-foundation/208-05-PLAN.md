## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| --tables CLI input -> DDL | table names are validated then quoted into CREATE/DROP TRIGGER statements in a migration that runs with DDL privileges |
| CLI flags -> filesystem | --migrations-path/--repo decide where the migration file is written |
| earlier migration files -> rerun detection | host files are read as text and regex-matched, never executed |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-208-12 | Tampering | gen.triggers --tables | high | mitigate | parse_tables! validates every segment (regex + 63 bytes) before any SQL is built; the rescue only rewraps the message; tests cover 70-byte, dash and three-part inputs with no file written |
| T-208-13 | Denial of service | rerun detection with cut trigger names | medium | mitigate | rerun? receives Naming.trigger_name/1 so a rerun of an overflowing table is detected and its generated down does not drop the live trigger; test in Task 2 |
| T-208-14 | Tampering | name-based rerun false positive (public.a_b vs a.b, shared 46-byte prefixes) | low | accept | yields only a conservative "already has triggers" result (keeps capture on during rollback); replaced by ON-clause matching in the next phase per D-11 |
| T-208-15 | Information disclosure | per-table function emission | medium | transfer | legacy function names are still emitted this phase; overflow raises (:derived) instead of sharing a truncated name; hashed emission lands in the next phase (NAME-02) |
