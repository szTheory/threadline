<objective>
Mirror TWIN-01 in the hex evaluator:
- Evaluator-local fixture tables for every shape.
- A trigger migration generated by the packaged `mix threadline.gen.triggers`, pinned by a regenerate-diff contract that runs the packaged generator (D-20).
- Thin round trips plus a no-findings assertion (D-21).

It runs in rehearsal mode through `mix verify.hex_evaluator`.

Note: the generated migration refreshes the evaluator's global `threadline_capture_changes()` in `public` to the current body, because at least one fixture table uses default mode. That is exactly what an adopter's first regenerate does. `posts` keeps capturing through the legacy no-argument branch, so `AdoptFromHexTest` and `LegacyPublicSchemaTest` must stay green unchanged. If either fails, that is an adopter-facing upgrade defect: stop and report it, do not edit those tests.

Output: fixture DDL, generated trigger migration, config key, schema modules, round-trip and contract tests.
</objective>
