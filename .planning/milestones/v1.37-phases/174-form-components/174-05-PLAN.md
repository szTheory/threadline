Module: Threadline.OperatorSurface.UI (use Phoenix.Component; alias Phoenix.LiveView.JS)

Existing components to follow as the signature/module pattern:
- label(assigns): attr :for, :class, :rest; slot :inner_block. Renders <label class="tl-label">.
- error(assigns): attr :id (required), :class, :rest; renders <p id={@id} class="tl-error"> with inline SVG icon (non-color validation).
- help(assigns): attr :id (required); renders <p id={@id} class="tl-help">.
- input(assigns): attr :id, :name (required), :value, :type (default "text"), :options, :checked, :rest.
    Has clauses: input(%{type: "checkbox"}), input(%{type: "select"}), input(%{type: "textarea"}), and the default input(assigns).
    Default renders <input type={@type} class="tl-control" ...>; checkbox uses class "tl-checkbox".
- field(assigns): monolithic composer — label + input + error + help, wires aria-describedby to "#{id}-help" and "#{id}-error".
- segmented_control(assigns): role="group", slot :segment with aria-pressed — the pattern to mirror for grouped controls.

ARIA-state precedent (use the same JS toggle pattern, NOT Alpine): popover/dropdown/accordion use
  phx-click={JS.toggle(to: "#...") |> JS.toggle_attribute({"aria-expanded","true","false"}, to: "#...")}
  phx-click-away={JS.hide(...) |> JS.set_attribute({"aria-expanded","false"}, ...)}
</interfaces>
