# Requirements: v1.20 - Scale and Governance Depth

## Themes

- **Safe Pruning:** Delete high-volume audit rows without long-running lock pressure.
- **Async Execution:** Move massive exports to durable background execution with truthful status and cleanup.
- **Operator Ergonomics:** Give operators actor-owned saved views and operational visibility.
- **Zero-Intrusion Scaling:** Preserve built-in defaults while exposing clean Oban and S3 seams for adopters who need them.

## Final Requirement Outcomes

### Infrastructure & State (INFRA)
- [x] **INFRA-01**: Introduce Ecto schemas and migrations for `threadline_export_jobs`, `threadline_retention_runs`, and `threadline_saved_views`.
- [x] **INFRA-02**: Define `Threadline.Storage` and `Threadline.ExportQueue` behaviours to formalize pluggable backend components for storage and background task orchestration.

### Retention Engine (RET)
- [x] **RET-01**: Implement a batched, autovacuum-aware retention pruner (`Threadline.Retention.Pruner`) that sleeps between chunked deletes to avoid long-running locks.
- [x] **RET-02**: Track retention runs in the DB (`threadline_retention_runs`) with start/stop times, duration, and deleted row counts.
- [x] **RET-03**: Provide a "Retention History" LiveView page inside the operator surface to monitor active pruning and past runs.

### Saved Views (VIEW)
- [x] **VIEW-01**: Implement actor-owned saved filter states relying strictly on the host's `actor_fn` to determine ownership without forcing a User schema dependency.
- [x] **VIEW-02**: Add a UI form to the existing raw timeline browse page to create, apply, and delete saved views.

### Async Exports (EXP)
- [x] **EXP-01**: Implement a built-in export orchestrator using `Task.Supervisor` and Ecto state (`threadline_export_jobs`) to run exports without blocking LiveView.
- [x] **EXP-02**: Stream massive CSV exports safely to `Threadline.Storage.Local` using `Repo.stream` inside a database transaction and `NimbleCSV`.
- [x] **EXP-03**: Add an "Export Status" UI inside the operator surface to monitor pending/running/completed exports and download completed artifacts.
- [x] **EXP-04**: Implement automatic expiration and cleanup of old export artifacts to prevent local or cloud storage bloat.

### Scale Adapters (ADAPT)
- [x] **ADAPT-01**: Provide a documented, optional Oban queue adapter (`Threadline.ExportQueue.Oban`) for enterprise scaling.
- [x] **ADAPT-02**: Provide a documented, optional S3 storage adapter (`Threadline.Storage.S3`) for multi-node deployments.
