## 5. Findings

### F1 — COMP-01/COMP-02 source uncommitted (headline finding, non-blocking, resolved at the UAT gate)

COMP-01 and COMP-02 are **functionally complete and user-approved live in both modes**, but their
**source is deliberately uncommitted**. The light overrides + status-chip "signal node" redesign
(D-09) and the coverage row hover-polarity fix are built in `lib/threadline/operator_surface/style.ex`
and verified live; `style_contract_test.exs` was re-baselined **25/25 green**; the user signed off
`:light` and `:dark` on the running surface.

The source is left in the working tree because ~660 of the 678 changed `style.ex` lines (and ~170 of
248 changed test lines) belong to the user's separate **uncommitted nav-overhaul lane**, and
interactive patch-staging is not available in this environment. A whole-file `git add` would bundle
the nav-overhaul work into a `feat(167)` commit. Per the user's decision, the Phase 167 source ships
**with** the nav-overhaul lane for v1.36. Only the clean `.planning` artifacts (the two SUMMARYs,
`LIGHT-REVIEW.md`, and the three deferral todos) were committed.

This is recorded honestly as a **finding, not a clean unqualified Complete**: the requirements are
functionally satisfied and human-verified, the committed-source state is pending, and the entanglement
resolves when the nav-overhaul lane lands. The End-of-milestone UAT gate (which walks the live
surface in all three modes) is the natural verification point; `closeout_readiness: pending-uat`
covers this directly. Source: `167-02-SUMMARY.md` (`status: built-verified-uncommitted`,
`source_committed: false`).

### F2 — REQUIREMENTS.md COMP bookkeeping

To keep REQUIREMENTS.md consistent with this finding, COMP-01/COMP-02 must NOT be silently flipped to
a clean `Complete`. Plan 170-02 (Task 2) records them with a precise status token that agrees with this
audit doc (built + verified live, source pending commit). BRAND-01/BRAND-02 are flipped to `Complete`
against Phase 170. This is documentation alignment, not a contradiction of any evidence.

None. No requirement is unsatisfied; no phase verification found a blocker; no integration drift; the
