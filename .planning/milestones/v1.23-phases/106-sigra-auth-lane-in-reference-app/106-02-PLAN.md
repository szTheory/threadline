Create `ThreadlinePhoenixWeb.OperatorUser`:

```elixir
def build_operator_user(scope, conn) do
  # Returns map with keys: :id, :organization_id, :role, :is_admin
  # or nil if no scope.user
end

def assign_from_scope(conn, _opts) do
  scope = conn.assigns[:current_scope]
  case build_operator_user(scope, conn) do
    nil -> conn
    user -> Plug.Conn.assign(conn, :current_user, user)
  end
end
```

Mapping rules (D-106-02c):

| field | source |
|-------|--------|
| `:id` | `scope.user.id` |
| `:organization_id` | `conn.private[:sigra_session].active_organization_id` OR `HelpDesk.get_organization_id_for_user(to_string(scope.user.id))` |
| `:role` | `HelpDesk.get_membership_role(user_id, org_id)` |
| `:is_admin` | Host allowlist on impersonator when `scope.impersonating_from` set; else allowlist on `scope.user` |

Host allowlist config:

```elixir
# config/dev.exs and config/test.exs
config :threadline_phoenix, ThreadlinePhoenixWeb.OperatorUser,
  admin_emails: ["admin@example.com"],
  admin_user_ids: []
```

`is_admin?/1` checks `admin_emails` and `admin_user_ids` lists.

Impersonation: when `scope.impersonating_from` is non-nil, compute `is_admin` from impersonator user only; do NOT use impersonated user's membership for `:support` access.

Create thin plug module `ThreadlinePhoenixWeb.Plugs.AssignOperatorUser` delegating to `OperatorUser.assign_from_scope/2`.
