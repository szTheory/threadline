## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> LiveView filter params | Untrusted query/form input crosses into `TimelineLive.handle_params/3` and `handle_event/3`. |
| LiveView -> query layer | Timeline requests scoped audit reads and counts through existing query/export functions. |
| Timeline row -> route pivots | Row data becomes transaction, actor, correlation, and row-history links. |
| Timeline -> export controller | Direct download links cross from LiveView affordance to HTTP controller/export auth. |
| Timeline -> export queue | Background export event creates an `ExportJob` only when exports are enabled and actor/scope context is preserved. |

## ASVS L1 Baseline

ASVS L1 applies. High-severity IDOR/scope bypass, unsafe atom creation, export-filter mismatch, forged export creation, XSS through refs, or route/auth weakening blocks completion.

| ASVS Area | Plan Mapping |
|-----------|--------------|
| V4 Access Control | Keep host scope callbacks for reads and export auth for direct downloads; never trust LiveView visibility as authorization. |
| V5 Validation, Sanitization, and Encoding | Keep allowlisted `FilterParams`, no unsafe atom creation, safe route segment encoding, and safe row-history identity gating. |
| V2/V3 Auth and Session | Preserve host-owned operator auth/session assigns and actor-owned saved views. |
| V14 Configuration | No route churn, dependency install, optional Phoenix boundary change, or public component API. |
