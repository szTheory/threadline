## Spacing Scale

Declared values are multiples of 4 and must map to existing `--tl-*` tokens where available.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, compact inline spacing, chip internals |
| sm | 8px | Button icon gaps, active chip gaps, row metadata gaps |
| md | 16px | Default component spacing, panel padding, page padding on desktop |
| lg | 24px | Larger row/control breaks, command-section breathing room |
| xl | 32px | Section gaps through `--tl-gap-section`, drawer/content rhythm |
| 2xl | 48px | Major page breaks where existing `--tl-space-12` is already available |
| 3xl | 64px | Reserved upper bound; do not add or reference a new operator token for Phase 184 |

Exceptions: existing operator CSS also uses `12px` (`--tl-space-3`) for field-grid and row gaps, `20px` (`--tl-space-5`) for some overlay padding, `40px` (`--tl-hit-area` and `--tl-control-height`) for pointer targets, `32px` compact controls, and `24px` chips/badges. Do not introduce any spacing value outside the existing token set.

Timeline-specific spacing rules:

| Surface | Contract |
|---------|----------|
| Command surface | Keep `.tl-timeline-command` compact: 8px internal command gap, 12px field-grid gap, 16px bottom margin before rows. Rows must remain visible early at 320, 375, and 768 px. |
| Inline filters | Use a single primary grid with `from`, `to`, `table`, `correlation_id`, then actions. No side rail. No second inline advanced-filter grid. |
| Drawer | Use 16px section gaps and existing `--tl-drawer-width: 760px`; mobile width must remain `min(var(--tl-drawer-width), 100vw)`. |
| Rows | Keep `.tl-change` padding at 16px, metadata/action gaps at 8px, and status stripe at 4px. No card nested inside a row. |
| Actions | Touch/click targets use 40px minimum; compact row buttons use existing 32px height only when the label remains readable. |

## Typography

Use exactly these four Phase 184 text sizes and two declared weights for new or retuned Timeline copy. Existing component internals that already use `--tl-weight-medium` may remain unchanged, but do not add new text roles around that weight.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label / metadata | 14px | 400 | 1.4 |
| Heading | 20px | 600 | 1.2 |
| Title | 24px | 600 | 1.15 |

Typography rules:

- Normal letter spacing is `0`.
- Uppercase metadata labels may use existing `--tl-tracking-caps: 0.12em`; do not add negative tracking.
- Use IBM Plex Mono only for table names, actor refs, correlation ids, transaction ids, row ids, command snippets, and exact timestamps.
- Timeline command title should stay compact, not hero-scale. Do not use 32px/48px display sizing on `/audit/timeline`.
- Long refs must wrap with `overflow-wrap: anywhere` or use `UI.ref/1`/`Presentation` truncation. Never clip the tail through CSS ellipsis on copyable values.

## Color

Use the existing dark-primary operator palette with light/system token lanes preserved.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | Dark `#0B1020` via `--tl-color-bg`; Light `#F7F9FC` | Page background, shell ground, Timeline canvas |
| Secondary (30%) | Dark `#141B2D` / `#1B253A`; Light `#FFFFFF` / `#EEF3FA` | Command surface, rows, drawer, cards/tools, nav surfaces |
| Accent (10%) | Dark `#4F8CFF`; Light `#1557C0` | Primary Apply action, links/pivots, active nav/filter cues, focus border/ring, selected states |
| Destructive | Dark `#FF8585`; Light `#A33434` | Delete saved view, error text, invalid/destructive states only |

Accent reserved for: `Apply`, `Apply filters`, transaction/actor/correlation route pivots, active filter/window chips, focus-visible ring/border, selected/current state, and primary status facts. Accent is not decoration and must not color every control.

Additional semantic color contract:

| Semantic | Token/value | Reserved for |
|----------|-------------|--------------|
| Signal | Dark `#4EDFD1`; Light `#0F8F85` | Correlation/live trace emphasis, copy success confirmation, connected-flow signal only |
| Warning | `--tl-color-warning-*` | capped/large result warnings, stale/reconnect trust states, audit-readiness caution |
| Success | `--tl-color-success-*` | all-captured/readiness-success facts only |
| Info | `--tl-color-info-*` | neutral informational alerts, window/fact stripe, non-blocking export notes |

Do not rely on color alone. Operation badges and alert rows need text labels, status stripes, or icons in addition to color.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Main command: `Apply`; drawer submit: `Apply filters` |
| Reset action | `Reset to last 24h` |
| Drawer entry | `Filters` with count badge only when advanced filters are active |
| Empty state heading | `No captured changes match this window` |
| Empty state body | `Widen the time range, or clear the table filter to search every audited table. Scoped views only show records you are authorized to see.` |
| Future-window empty body | `This window has no matching changes, but Threadline has audit data outside it. Move the window back toward recent activity or clear filters.` |
| Error state | `Timeline filters could not be applied. Fix the {target} filter, then apply filters again. {validator detail}` |
| Unknown table state | Table filter `{table}` is not audited. Select an audited table or clear the table filter. Append audited table list only when present. |
| Export queued success | `Background export requested. View progress on the Export Status page.` |
| Export failure | `Background export could not start because the built-in export runtime is unavailable.` or `Background export could not start: {reason}.` |
| Destructive confirmation | No audit-data destructive action exists in Timeline. Saved-view delete uses icon-only `Delete {view.name}` and no modal/type-confirm; keep it confined to the drawer and do not add retention/redaction destructive copy. |

Voice rules:

- Use Threadline language: Timeline, Audit Change, Audit Transaction, Actor, Correlation, row history, current view, filter, scan, open, copy, carry, queue export, download, widen, clear, refresh.
- Avoid backend internals in primary copy unless they explain scope, trust, caps, or export auth.
- Avoid exclamation marks, generic hype, "robust", "seamless", "powerful", SIEM framing, immutable-ledger framing, and compliance-suite framing.
- Errors must state what failed, why if known, and what to do next.
- Empty states must preserve distinct meanings: first-run no data, filtered no data, future window, unknown table, invalid filter, scoped view, and export unavailable are not interchangeable.

## Timeline Workflow Contract

The first-viewport workflow is filter -> scan -> open transaction/row history -> export current view.

### Command Surface

| Element | Contract |
|---------|----------|
| H1 | Use `Investigate audit activity` unless implementation proves a better on-brand equivalent. One H1 only. |
| Lede | Explain starter filters briefly: time window, table, correlation id; actor/schema filters belong in the drawer. |
| Inline filters | Show only `from`, `to`, `table`, `correlation_id`. Use native datetime/text/datalist controls. |
| Advanced filters | Keep `table_schema`, `actor_kind`, `actor_id` in the drawer. Actor id is disabled when actor kind is anonymous. |
| Apply semantics | Batch submit only through `phx-submit="apply"`. No `phx-change` filtering on Timeline. |
| URL state | Result-changing filters must stay in query params through `FilterParams`, `push_patch`, and `handle_params/3`. |
| Facts | Show exactly the useful result facts: window, matching changes, audit-readiness posture. Avoid duplicate count/window lines except the existing live status caption if accessibility proof requires it. |
| Active filters | Show window chip, detail text, and active table/schema/actor/correlation chips. Empty copy is `No table, schema, actor, or correlation filter`. |
| Main handoff | The command area may expose at most one low-noise handoff entry; default is no main handoff, with utilities in the drawer. |

### Timeline Rows

| Element | Contract |
|---------|----------|
| Row model | Hybrid scan-first row. Do not convert to a fixed dense table. |
| First line | Operation badge, table ref, exact/human time. |
| Pivots | Actor and correlation remain visible when present and URL-backed. |
| Primary action | `Open transaction` remains the primary row action. |
| Row history | Add/direct row-history action only when a single safe routeable row identity can be built. Omit for missing, composite, unsupported, or ambiguous identity. |
| Copy controls | Use only for values operators paste elsewhere: correlation id, transaction id when visible, row/table identity when useful, and full refs. Every control needs a specific label such as `Copy correlation id` and copies the full value, never the visible truncated label. |
| Menus/expanders | Do not hide primary pivots behind overflow menus or expandable rows. |
| Motion | No row entrance animation or decorative streamed-row motion. Use hover/focus states and operation/status stripes only. |

### Drawer And Handoff

| Section | Contract |
|---------|----------|
| Drawer title | `Filters and handoff` |
| Drawer description | `Refine the current Timeline query, save reusable views, or package this result set for a handoff.` |
| Section order | Advanced filters -> Investigation checks -> Export actions -> Saved views |
| Investigation checks | Coverage and Evidence are secondary checks. Do not turn Timeline into a generic command center. |
| Export actions | `Carry to Exports` is the safest primary handoff. `Queue export` is secondary. CSV/JSON/NDJSON direct links are grouped under export/download affordances and remain real HTTP links. |
| Export security | LiveView visibility is not the security boundary. Direct downloads remain protected by `ExportController`, `ExportAuthPlug`, and canonical `FilterParams`. |
| Saved views | Actor-owned only. Do not render save/apply/delete saved-view affordances when no actor is available. |
| Focus behavior | Opening drawer moves focus inside; Escape and Close hide the drawer; focus returns to the invoker; Tab remains usable without trapping the operator outside the workflow. |

## Responsive And Keyboard Contract

| Viewport | Required behavior |
|----------|-------------------|
| 320 px | No horizontal page overflow; inline filters stack; drawer fits `100vw`; row table/correlation/actor refs wrap or truncate safely; row action remains reachable. |
| 375 px | Same as 320 with rows visible early after command; active filters and count copy cannot push the first row below an excessive intro block. |
| 768 px | Two-column inline filter grid; shell/nav remains usable; drawer focus/escape/return still works. |
| 1024 px | Command and rows keep scan-first hierarchy without side rail. |
| 1440 px | Desktop layout can align row actions trailing, but rows remain hybrid cards/lists, not a fixed table. |

Keyboard order:

1. Skip link, shell nav, Timeline H1/command.
2. `from`, `to`, `table`, `correlation_id`.
3. `Filters`, `Reset to last 24h`, `Apply`.
4. Result rows: actor pivot, correlation copy, correlation Timeline pivot, `Open transaction`, safe row-history link if present.
5. Pager Older/Newer controls.
6. Drawer controls when opened: Close, advanced filters, `Apply filters`, Coverage/Evidence, Queue export, Carry to Exports, download links, saved-view controls.

Keyboard rules:

- Enter on the filter form submits one batch Apply.
- Browser back/forward must restore URL-backed filter state.
- Copy controls need accessible names and visible focus.
- Disabled/reconnect-mutating links use `aria-disabled="true"`, `tabindex="-1"`, and dimming; server/controller checks still own enforcement.
- Do not introduce custom widgets when native controls satisfy the need.

## State Lattice

| State | Visual treatment | Copy/action |
|-------|------------------|-------------|
| First-run empty | `UI.empty_state` variant `never`, history icon | State no captured changes in window; action `Clear filters` or reset to last 24h as appropriate |
| Filtered no-data | `UI.empty_state` variant `no_data`, funnel icon | Heading/body from Copywriting Contract; action `Clear filters` |
| Future-window empty | Empty state with future-window body | Tell operator data exists outside the window; next action is move window back or clear filters |
| Invalid filter | `tl-alert--error`, `role="alert"` | Name target filter and tell operator to fix then apply again |
| Unknown table | `tl-alert--info`, `role="status"` | Name table, state it is not audited, select audited table or clear table filter |
| Scoped/authorized caveat | Include caveat in no-data body and trust copy | `Scoped views only show records you are authorized to see.` |
| Export hidden/denied | Do not render export affordances; forged events no-op | Do not imply LiveView visibility is auth |
| Export unavailable/failure | Preserve rows; show export error feedback | Use background export failure copy and keep Queue export path stable |
| Large result | `tl-alert--info` | Large export — will stream in chunks. |
| Capped result | `tl-alert--warning`, `role="alert"` | Truncated to first 10,000 rows. Use `mix threadline.export --max-rows N` for the full window. |
| Loading | Existing `UI.loading_state` when Timeline directly renders loading | Do not replace last-good rows unless no safe data exists |
| Stale/reconnecting | Existing reconnect banner or `UI.stale_banner` above data | Label last-good data and offer retry/refresh if Timeline renders the state |
| Long refs | `UI.ref` or `Presentation` truncation plus title/full copy | Preserve full values in `data-tl-copy`; allow wrapping |
| Dense pagination | `UI.pager` with honest shown/match count | Older disabled/hidden behavior must match existing pager contract |

## Motion Contract

| Interaction | Contract |
|-------------|----------|
| Drawer open/close | Existing `--tl-motion-base: 180ms`, opacity/transform only |
| Copy success | Existing Signal-Cyan pulse and `Copied` chip are allowed |
| Button press | Existing `scale(0.96)` active feedback is allowed |

| Prohibited | `transition: all`, new keyframes for Timeline rows, decorative blobs, decorative background gradients, layout-jumping animation |
