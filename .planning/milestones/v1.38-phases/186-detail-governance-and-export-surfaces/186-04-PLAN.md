<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser to export LiveView | Timeline/Evidence export context query params and queue events are untrusted. |
| Browser to HTTP export controller | `/exports/download/:job_id` is direct HTTP and must remain actor/status/expiry authorized. |
| Feature-gate assigns to rendered controls | Export feature gates decide which links and buttons can exist. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-186-16 | Spoofing | Completed export links | mitigate | Real links are focusable and no disabled-looking attributes remain; controller tests enforce authorization and status. |
| T-186-17 | Tampering | Export queue event | mitigate | Keep server-side validation for enabled exports and valid Timeline context; tests forge denied/invalid queue events. |
| T-186-18 | Information Disclosure | Direct export downloads | mitigate | Preserve `ExportController` actor ownership, status, expiry, and storage tests. |
| T-186-19 | Elevation of Privilege | Feature-gated Exports controls | mitigate | Omit gated controls from disabled surfaces and preserve UnsupportedView shell gates. |
| T-186-SC | Tampering | Package/dependency surface | mitigate | No package-manager install or dependency file edits are part of this plan. |
</threat_model>
