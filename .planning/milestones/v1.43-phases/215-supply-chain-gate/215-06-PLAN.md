  active suppression (HEX_IGNORE_* env non-empty, a global `mix hex.config` ignore value other than

  "vacuous audit is skipped" rule the script already applies to fetch failures). `unknown` already
  fails the lane via the unchanged deps-health.yml step.

  Verified during planning: with no mix.lock present `--check-locked` also fails (the lock would be
  created), so review finding WR-03 (missing lockfile reported clean) is mitigated at the real-Mix
  level by this change without a new seam; it is recorded as mitigated in deferred-items.md.
- WR-08 (weekly lane has no Hex floor) is NOT a one-line change and stays deferred.
