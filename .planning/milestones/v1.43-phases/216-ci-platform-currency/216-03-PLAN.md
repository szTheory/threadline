| Boundary | Description |
|----------|-------------|
| Release job → dependency compile | sync-release-pr-pins compiles every dependency; compile-time code can read anything left in `.git/config` |
| Workflow SHA ↔ target ref | Release jobs execute the workflow file from one commit and build code from another (release branch or tag) |
| Third-party actions | actions/checkout and erlef/setup-beam run with the job token |

| T-216-07 | Information Disclosure | new toolchain checkout in sync-release-pr-pins persisting the token | high | mitigate | `persist-credentials: false` on every toolchain checkout (classifier-enforced) and a checkout-count == flag-count assertion in release_control_plane_contract_test.exs |
