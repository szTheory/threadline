## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| audit row data -> Presentation helpers | Untrusted database values become UI text tokens. |
| CSS primitives -> operator surface | Shared classes affect all mounted `/audit` views. |
| package supply chain | Phase explicitly forbids new package installs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-138-01 | Tampering / Information Disclosure | `Presentation.value_token/1` and `change_value_token/2` | mitigate | Return plain strings/maps only; render through HEEx interpolation in downstream plans; no `Phoenix.HTML.raw` or safe HTML helpers. |
| T-138-02 | Spoofing | `actor_transaction_summary/1` | mitigate | Use explicit `Changes unavailable` fallback when summary data is absent; do not invent first-table labels without input changes. |
| T-138-03 | Information Disclosure | `coverage_remediation/1` | mitigate | Command helper exposes only table names already visible on Coverage; no secrets, schema credentials, or host config values. |
| T-138-04 | Denial of Service | map/list value formatting | mitigate | Use deterministic bounded presentation strings; tests cover maps/lists without recursive raw inspection in templates. |
| T-138-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs are planned; Package Legitimacy Audit says none. If an executor attempts install, stop and run slopcheck/human gate. |
</threat_model>
