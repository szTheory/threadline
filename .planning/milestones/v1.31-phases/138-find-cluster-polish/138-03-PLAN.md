<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL params -> Timeline filters | User-controlled query params become validated filter state. |
| scoped operator -> Timeline query/export count | Host-owned scope must constrain every count and row query. |
| audit row refs -> copy/title UI | Authorized values become titles/copy payloads. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-138-09 | Tampering | Timeline `FilterParams` | mitigate | Preserve existing `FilterParams` validation and invalid-filter error path; do not parse params ad hoc. |
| T-138-10 | Elevation of Privilege | Timeline row and outside-window count queries | mitigate | Use existing `scope_aware_opts/1` for row, count, and outside-window count calls. |
| T-138-11 | Information Disclosure | correlation/table title/copy affordances | mitigate | Expose full values only for rows already rendered to the authorized operator; do not add hidden preloads for unauthorized rows. |
| T-138-12 | Spoofing | inert journey strip | mitigate | Demote to non-clickable legend so `PACKAGE` does not imply Phase 140 closed export flow. |
| T-138-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs are planned; Playwright dependency already exists. |
</threat_model>
