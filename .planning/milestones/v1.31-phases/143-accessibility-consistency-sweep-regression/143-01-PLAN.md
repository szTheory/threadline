# Plan 143-01: Accessibility Primitive Baseline

## Objective

Lock the operator-surface accessibility baseline for focus-visible, contrast, ARIA/name/role/state, keyboard reachability, and non-color-only status meaning.

## Tasks

1. Add source contracts in `style_contract_test.exs` for contrast token ratios, focus-visible coverage, and no focus-removal drift.
