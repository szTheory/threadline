## Motion Principles

1. Motion is a design-system contract, not decoration. Every shipped animation must have an inventory row with selector/name, trigger, persona/JTBD, rationale, token, properties animated, and reduced-motion outcome.
2. Motion must clarify continuity, completion, or newly arrived state. Allowed jobs are orientation, record/proof continuity, copy confirmation, drawer entry, low-frequency reveal, and policy success.
3. Motion must not slow operator work. High-frequency scan surfaces, pagination, filters, timeline streams, table sorting, and repeated row updates must stay static unless the inventory documents a specific triage benefit.
4. Prefer compositor-friendly properties: `opacity`, `transform`, and `box-shadow` for the existing copy pulse. Layout-affecting animation is allowed only for the existing details disclosure pattern and must be named in the inventory.
5. Signal Cyan thread-draw is the signature motif. It is reserved for completed path, primary entry, evidence/proof progression, or trust-restored moments.
6. No broad visual redesign, route behavior changes, mobile layout changes, JavaScript animation libraries, scroll-jacking, looping decorative motion, or screenshot-baseline work belongs in Phase 141.

## Motion Tokens

Allowed timing and distance tokens:

| Token | Value | Usage |
|-------|-------|-------|
| `--tl-motion-fast` | `120ms` | Hover/focus/active transitions and short feedback |
| `--tl-motion-base` | `180ms` | Default enter, reveal, copy pulse, drawer, disclosure |
| `--tl-motion-slow` | `240ms` | Signature thread-draw only |
| `--tl-motion-stagger` | `40ms` | Staggered reveal delay between siblings |
| `--tl-motion-distance-sm` | `8px` | Subtle rise-in Y distance |
| `--tl-motion-distance-md` | `16px` | Drawer X distance |
| `--tl-ease-standard` | `cubic-bezier(0.2, 0, 0, 1)` | Controls, drawer, standard transitions |
| `--tl-ease-out` | `cubic-bezier(0.16, 1, 0.3, 1)` | Entrances, reveal, thread-draw, copy pulse |
| `--tl-transition-fast` | `var(--tl-motion-fast) var(--tl-ease-standard)` | Generic interactive transitions |

Literal duration rule: no new literal `ms` values. Existing `120ms` thread-draw delays may remain only if documented as the signature draw delay, or be replaced with a token before approval. Existing reduced-motion `1ms`/`0ms` overrides are allowed inside `@media (prefers-reduced-motion: reduce)` only.

| Drawer entrance | `tl-drawer-in` on `.tl-subview` | Subview/dialog mount | P1/P4 context change without disorientation | `--tl-motion-base`, `--tl-ease-standard`, `--tl-motion-distance-md` | Drawer appears in final position |
| Disclosure expansion | `block-size`/`content-visibility` on `.tl-policy__row::details-content` | Details open/close | P3 compare configured vs deployed policy state | `--tl-motion-base`, `--tl-ease-out` | Disclosure opens/closes without animated sizing |
| Retention run reveal | `tl-rise-in` on `#retention-runs > tr` | New prune/run row arrives | P3/P4 confirm consequential completion | `--tl-motion-base`, `--tl-ease-out` | Row appears immediately |
| Row-history stagger | `tl-rise-in` on `.tl-subview__timeline > *` | Row-history drawer mount | P1 follow event sequence | `--tl-motion-base`, `--tl-ease-out`, capped `--tl-motion-stagger` | Items appear immediately, ordered DOM remains unchanged |

| Copy confirmation | `tl-copy-pulse` on `.tl-copy.is-copied` | Copy success class toggled | P2/P3 confirm copied identifier | `--tl-motion-base`, `--tl-ease-out` | Static `Copied` chip remains; pulse collapses |
| Journey/proof thread | `tl-thread-draw` on `.tl-journey-rail::before` | Journey/proof rail mount | P3 evidence continuity | `--tl-motion-slow`, `--tl-ease-out`, signature delay only | Rail appears without draw delay |
| Policy success thread | `tl-thread-draw` on `.tl-policy__success::after` | Redaction drift reaches all-clear | P3 trust restored | `--tl-motion-slow`, `--tl-ease-out`, signature delay only | Success line appears immediately |
| Active press | `.tl-button:active { transform: ... }` | Pointer activation | P2/P4 tactile control feedback | `--tl-transition-fast` | Transform is reset to `none` |

New keyframes are forbidden unless the phase plan includes a named inventory row, a rationale tied to a persona/JTBD, and a source-contract test proving token use and reduced-motion coverage.

## Inventory Schema

Phase 141 must produce a motion inventory artifact under `.planning/phases/141-motion-micro-animation/`.

Required columns:

| Column | Required content |
|--------|------------------|
| `id` | Stable short ID, e.g. `M-01` |
| `selector_or_keyframe` | CSS selector and keyframe/pattern name |
| `surface` | Home, Find, Prove, Policy, Retention, Drawer, Shared control |
| `trigger` | User/system event that starts motion |
| `persona_jtbd` | Persona and JTBD served |
| `rationale` | One sentence explaining operational value |
| `token` | Exact `--tl-motion-*`, ease, and distance tokens used |
| `properties` | CSS properties animated or transitioned |
| `frequency` | One-shot, low-frequency, or high-frequency |
| `reduced_motion` | Final expected behavior under `prefers-reduced-motion: reduce` |
| `source` | File and selector location |
| `status` | `keep`, `neutralize`, `justify`, or `remove` |

Every `animation:` and non-trivial `transition:` in `lib/threadline/operator_surface/style.ex` must map to exactly one inventory row. Generic color/background/border/focus transitions may be grouped as `Shared interactive transitions`; transform transitions require explicit listing.

## Reduced-Motion Contract

1. A scoped `@media (prefers-reduced-motion: reduce)` block must cover `.threadline-ui *`, `.threadline-ui *::before`, `.threadline-ui *::after`, and `.tl-policy__row::details-content`.
2. Reduced motion must set animation and transition durations to the existing collapsed values, remove animation delay, force one iteration, and keep scroll behavior automatic.
3. Transform-sensitive surfaces must land in final readable state. `.tl-button:active` must reset transform to `none`; any newly introduced transformed selector must receive either blanket coverage or a targeted reset.
4. Reduced motion must preserve non-motion state confirmation. Example: `.tl-copy.is-copied::after` remains visible as static copy confirmation even when the pulse collapses.
5. Browser checks should use focused reduced-motion assertions through the existing Playwright configuration, not screenshot-diff baselines.

## Spacing Scale

Phase 141 must not alter base visual scales. It may only reference existing tokens:

| Token | Value | Usage |
|-------|-------|-------|
| `--tl-space-1` | `4px` | Inline gaps, chip offsets |
| `--tl-space-2` | `8px` | Compact gaps; matches `--tl-motion-distance-sm` |
| `--tl-space-4` | `16px` | Panel/control spacing; matches `--tl-motion-distance-md` |
| `--tl-space-6` | `24px` | Page padding |
| `--tl-space-8` | `32px` | Larger layout gaps |
| `--tl-space-12` | `48px` | Major breaks |

Exceptions: existing `12px`, `20px`, and `40px` spacing tokens remain in force; Phase 141 must not add spacing tokens. Motion distances are limited to `8px` and `16px`.

## Forbidden Patterns

- New animation libraries, timers, requestAnimationFrame loops, scroll-triggered flourishes, parallax, marquee, shimmer, skeleton shimmer, or infinite decorative loops.
- Literal duration/delay values outside tokens, except reduced-motion collapse values and the documented signature thread delay if retained.
- Animating layout, width, height, margin, padding, top/right/bottom/left, filter, blur, or color-only pulses unless explicitly inventoried and justified.
- Animating high-frequency timeline rows, pagination, filters, table sorting, or repeated LiveView stream updates.
- Using Signal Cyan thread-draw for generic hover, decorative separators, or every card.
- Motion that hides state, delays task completion, depends on hover only, or removes static confirmation under reduced motion.
- Phase 142 responsive layout fixes or Phase 143 accessibility/screenshot-diff infrastructure.
