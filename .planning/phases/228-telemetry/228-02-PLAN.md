<interfaces>
error_kind mapping chosen for D-06 (Claude's discretion, all four atoms are reachable):
- `:exception` — a raise (eager functions; chunked stream raise; orchestrator outer rescue; completion_fn raising, whose rescued struct reaches compensation). `exception:` is the struct's module.
- `:transaction_failed` — the export transaction function returned `{:error, _}` or an unexpected value, or completion_fn returned a non-exception error (the job-status update failed). `exception: nil`.
- `:storage_error` — reading the temp file failed or the storage adapter's put returned `{:error, _}`. `exception: nil`.
- `:client_closed` — the chunked download's `Plug.Conn.chunk/2` returned `{:error, _}` (Plug adapters report a gone client as `{:error, :closed}`; any chunk-write error means the client did not receive the export). `exception: nil`.
</interfaces>
