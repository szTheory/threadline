Existing responsive CSS anchors:
- `.tl-topbar__nav` is the explicit internal horizontal scroll owner: `overflow-x: auto`, `min-width: 0`, and hidden scrollbars.
- `.tl-toolbar__form` is column/100% width in the base layer; it should wrap in the `768px` tablet layer.
- `.tl-table-wrap` is an allowed internal overflow owner; `.tl-table--responsive` currently has hidden `thead`, block rows/cells, and `td::before { content: attr(data-label); }`.
- `.tl-subview` is fixed full-width on phones with `width: 100vw`, `min-height: 100dvh`, and internal `overflow: auto`; desktop may use `width: min(var(--tl-drawer-width), 100vw)`.
- Long value primitives already include `.tl-secondary-ref`, `.tl-value`, `.tl-param`, `.tl-record-card__ref`, and `.tl-kv__row` with `min-width: 0` and wrapping patterns.

Phase 142 locked decisions:
- D-04: topbar nav may scroll internally; root/document horizontal overflow is not acceptable.
- D-05: tables should be shared mobile-first labelled cards and restore true table semantics on desktop.
- D-06: filters/toolbars stack on phones, wrap at tablet, compact on desktop.
- D-07: drawers/subviews fit 375px without clipping primary controls or values.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-142-05 | Denial of Service | narrow operator workflows | mitigate | Tables, toolbars, drawers, and long values must wrap or own internal scroll so controls remain reachable at 375px. |
| T-142-06 | Tampering | root overflow masking | mitigate | Source contract and grep gate forbid blanket root/body `overflow-x: hidden`. |
| T-142-07 | Repudiation | responsive primitive behavior | mitigate | ExUnit source contracts name the required selectors, media layers, and internal scroll owners. |
| T-142-08 | Information Disclosure | hidden/clipped values | mitigate | Long values wrap inside cards/drawers instead of clipping outside viewport; no data semantics are changed. |
| T-142-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs. CSS fixes must use existing project stack and tokens. |
</threat_model>
