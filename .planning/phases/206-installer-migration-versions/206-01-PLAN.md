<objective>
Fix the installer's duplicate-migration-version defect (205-REVIEW CR-01) for the whole
defect class, and fold in the partial re-run advice defect (205-REVIEW WR-03).

Purpose: today `mix threadline.install` stamps each migration with the wall-clock second, so a
fresh adopter's `mix ecto.migrate` raises `(Ecto.MigrationError) migrations can't be executed,
migration version <N> is duplicated`. `mix threadline.gen.triggers` has the byte-identical stamp
and collides with install when scripted together. The installer also tells a partial re-run to
switch to a dedicated schema, which would split Threadline across two schemas.

Output: one hidden helper module (Rails `next_migration_number` pattern, D-01..D-04), both Mix
tasks rewired to it, the three-branch storage-schema advice (D-06..D-08), and file-level
regression tests proven RED first (D-09, D-10). Commits are releasable `fix(...)` (D-11).
