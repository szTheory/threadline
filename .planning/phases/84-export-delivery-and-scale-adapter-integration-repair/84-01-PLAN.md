## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Actor-owned route -> backend delivery | Authorization and completed-state truth happen before storage-specific delivery begins. |
| LiveView markup -> bearer URL generation | Remote download URLs must not be embedded in long-lived HTML because they are bearer tokens with expiry. |
| Durable job state -> user-visible actions | The operator surface must not show actionable downloads for non-ready or unavailable jobs. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-84-01 | Elevation of privilege | `ExportController.download/2` | mitigate | Keep actor/job authorization above all local or remote delivery branching. |
| T-84-02 | Information disclosure | remote delivery URL handling | mitigate | Generate adapter-backed URLs only on click inside the controller; do not render presigned URLs directly into the LiveView. |
| T-84-03 | Repudiation | operator status UI | mitigate | Render truthful placeholders, failures, and `Download Export` affordances only when the backend can actually serve the artifact. |
</threat_model>
