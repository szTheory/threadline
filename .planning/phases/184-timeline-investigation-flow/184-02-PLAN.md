<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Query result -> Timeline state copy | Counts, filters, table metadata, and export availability become operator trust messages. |
| Long refs -> browser/copy controls | Potentially long actor/correlation/table/row/transaction values render into markup and copy metadata. |
| CSS/layout -> operator usability | Narrow-width, focus, drawer, pager, and row CSS can block keyboard/mobile operators. |
| Stale/reconnect state -> operator trust | Last-good data and refresh failures can be misunderstood if labels are wrong. |

## ASVS L1 Baseline

ASVS L1 applies. This plan blocks on misleading authorization/scope copy, XSS/copy metadata drift, focus/overflow denial, stale-data trust confusion, or unsafe state fallback.

| ASVS Area | Plan Mapping |
|-----------|--------------|
| V4 Access Control | Scoped/no-data copy must not imply the operator saw all records when host scope limits results. |
| V5 Validation, Sanitization, and Encoding | Long refs render through HEEx, `UI.ref`, and `Presentation` helpers with full-value copy intact. |
| V12 File/Resource | Export unavailable/failure copy must preserve rows and not imply queue/download success. |
| V14 Configuration | No dependency, token, screenshot, or visual SaaS expansion. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-184-06 | Information Disclosure / Repudiation | Empty/scoped/stale copy | mitigate | Tests assert distinct state meanings and scoped-view caveat; stale data is labeled when rendered. |
| T-184-07 | Tampering / XSS | Long refs and copy controls | mitigate | Use `UI.ref`/`Presentation` and assert copy full value differs from truncated visible label. |
| T-184-08 | Denial of Service | Responsive CSS, drawer, pager, focus | mitigate | Source contracts assert no overflow hiding workaround, token spacing, focus visibility, drawer width, and stable controls. |
| T-184-09 | Repudiation | Export unavailable/failure feedback | mitigate | Copy names queue/runtime failure while preserving current rows and action stability. |
| T-184-10 | Denial of Service | Motion/layout jumps | mitigate | Style contracts forbid Timeline row animation and `transition: all`; reduced-motion behavior remains enforced. |
| T-184-SC | Tampering | Package installs | accept | No package-manager install is part of this plan; existing private UI primitives are reused. |
</threat_model>
