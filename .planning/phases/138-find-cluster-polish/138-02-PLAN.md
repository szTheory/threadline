## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-138-05 | Tampering / Information Disclosure | Transaction value rendering | mitigate | Use `Presentation.change_value_token/2` data maps and HEEx interpolation; remove template `inspect/1` for field values. |
| T-138-06 | Information Disclosure | Transaction and Row-history scope | mitigate | Preserve existing `scope`, `scope_query_fn`, `surface`, and params; keep scoped tests green. |
| T-138-07 | Information Disclosure | Copy/title affordances | mitigate | Copy/title only expose transaction/correlation values already authorized and visible on the page. |
| T-138-08 | Denial of Service | INSERT data_after derivation | mitigate | Derive fields only from the already loaded `change.change_diff["data_after"]` map; do not add new queries or unbounded data loading. |
| T-138-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs are planned; stop if any install is attempted. |
