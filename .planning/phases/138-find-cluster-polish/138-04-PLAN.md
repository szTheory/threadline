<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| scoped operator -> Actor summary data | Actor summaries could leak table/change labels outside scope if loaded unsafely. |
| Coverage schema param -> database catalog lookup | User-controlled schema input reaches coverage lookup. |
| Coverage row values -> remediation copy/copy button | Visible table names become CLI snippets and copy payloads. |
| Playwright browser -> demo app | Browser UAT exercises authenticated operator surfaces. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-138-13 | Information Disclosure / Elevation of Privilege | Actor summaries | mitigate | Use one unscoped bounded batch query only when no scope is active; scoped sessions render `Changes unavailable` unless a scoped batch query has a passing leak test. |
| T-138-14 | Denial of Service | Actor summary loading | mitigate | Fetch summaries once per visible page by transaction id; forbid per-row `audit_changes_for_transaction/2` calls and public API churn. |
| T-138-15 | Tampering | Coverage schema input | mitigate | Preserve existing regex validation and parameterized `pg_namespace` lookup; do not alter `Threadline.Health.trigger_coverage/1`. |
| T-138-16 | Spoofing | Coverage remediation | mitigate | Label `Add capture` as guidance and show Mix command plus verify follow-up; do not imply in-browser mutation. |
| T-138-17 | Information Disclosure | Coverage copy/title controls | mitigate | Copy only visible table remediation commands; no host secrets or config values. |
| T-138-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs are planned; Playwright already exists. |
</threat_model>
