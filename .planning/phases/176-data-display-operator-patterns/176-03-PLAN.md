<objective>
Adopt the Plan-02 components across the read-only / display operator pages to close the DATA-01 copy+truncation gaps and land the DATA-03 data-state taxonomy on these pages — and kill the CSS double-truncation. This is the non-destructive consumer migration (the destructive-action pages and the coverage flatten are Plans 04/05). It turns the Plan-01 ref-copy-equals-full and per-page typed-reason RED tests GREEN for these pages.

Purpose: the transaction copy footgun (`data-tl-copy={ref.title}` at L120-121/145) is a confirmed live bug — `.title` is the full value only by coincidence and would silently copy a truncated value the instant `secondary_ref` truncates `.title`. KV snapshot and diff before/after cells are exactly where an operator grabs a value to paste into SQL and today they render raw, untruncated, with no copy. And the inert `text-overflow:ellipsis` on `.tl-secondary-ref` is a latent tail-clipper at 320px. Fixing all three converges the forensic contract.
Output: `transaction/actor/timeline/evidence/export_status` migrated to `ref/1` + `kv/1` + truncated diff cells + the data-state family; `.tl-secondary-ref` ellipsis removed and `overflow-wrap:anywhere` added in `style.ex` with the paired `style_contract_test.exs` assertion updated in the same task.
</objective>
