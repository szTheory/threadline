# Phase 176 — UI Design Contract

> Visual and interaction contract for Threadline's `/audit` data-display surfaces. Generated by gsd-ui-researcher from a fully-locked CONTEXT (D-01..D-22). Verified by gsd-ui-checker.
>
> **Reframe:** this phase is *fix-and-consolidate*, not greenfield. The contract below converges five drifting render paths onto a small set of internal `Threadline.OperatorSurface.UI` function components, fixes forensic footguns (copy-the-truncated-value, client-only destructive confirm), and locks the data-state taxonomy. All values are sourced from `brandbook/tokens.json`, `brandbook/tokens.css` (`--tl-*` contract), and the 173/174/175 component conventions.

## Spacing Scale

Declared values from `brandbook/tokens.json` / `tokens.css` (`--tl-space-*`). All multiples of 4. Use tokens, never raw px.

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| `--tl-space-1` | 4px | Icon-to-label gaps, copy-chip inset, `data-status` stripe offset |
| `--tl-space-2` | 8px | Compact element spacing, kebab menu item padding-y, badge inset |
| `--tl-space-3` | 12px | KV row gap, table cell padding-y, dropdown menu padding |
| `--tl-space-4` | 16px | Default element spacing, table cell padding-x, card body padding |
| `--tl-space-5` | 20px | Section inner padding |
| `--tl-space-6` | 24px | `--tl-gap-stack` between page-stack siblings (coverage flatten target) |
| `--tl-space-8` | 32px | Major section breaks, empty/state block vertical padding |
| `--tl-space-12` | 48px | State-block (loading/empty/error) centered min-height padding |
| `--tl-space-16` | 64px | Page-level top spacing |

**Exceptions:** Interactive controls (kebab trigger, copy button, T2/T3 modal buttons) must meet a **44×44px** minimum touch target on touch viewports (320/375), achieved via padding + min-height — this is a target floor, not a new spacing token. Stacked-table (`<td>` grid) row rhythm at ≤480px keeps the existing `data-label` `::before` layout; no new spacing introduced.

## Typography

From `brandbook/tokens.json` / `tokens.css`. The brand defines a broader scale; **this phase uses exactly the four roles below** plus mono for machine values. Two weights in active use (regular 400 + strong 600); medium 500 is reserved for the existing `page_header`/nav and not introduced here.

| Role | Size | Weight | Line Height | Token / usage |
|------|------|--------|-------------|---------------|
| Body | 16px | 400 regular | 1.5 | `--tl-font-size-body` / `--tl-line-body` — state copy, lede, KV values, table cells |
| Label | 14px | 600 strong | 1.4 | `--tl-font-size-label` / `--tl-line-label` — KV keys, `<th>` / `data-label`, metric labels; uppercase metadata may add `--tl-tracking-caps` (0.12em) |
| Heading | 20px | 600 strong | 1.2 | `--tl-font-size-heading` / `--tl-line-heading` — state headings (`empty_state __title`, `error_state` focus heading), card titles |
| Mono | 15px | 400 regular | 1.5 | `--tl-font-mono`, `--tl-font-size-ui` — IDs, ARNs, hashes, paths, `<code>` copy targets, diff before/after cells |

Rules: letter-spacing `0` for normal text; mono **never** for prose; sentence case everywhere; the `ref` `<code>` element uses mono and carries `data-tl-copy={ref.full}`.

## Color

60/30/10 split mapped to the dark default lane (`--tl-*` resolve per lane for light/system). **Color is signal, never decoration; never the sole carrier of operation/severity/state** (brand-book.md:297) — every status, state, and danger cue pairs color with an icon **shape** and/or text.

| Role | Value (dark lane) | Token | Usage |
|------|-------|-------|-------|
| Dominant (60%) | `#0B1020` / `#141B2D` | `--tl-color-bg` (threadline-black / graphite) | Page background, page-stack sections, table surface |
| Secondary (30%) | `#1B253A` / `#202B42` | `--tl-color-surface` / `--tl-color-surface-hover` | Cards (one-boundary-per-unit), metric tiles, dropdown menu, modal surface, raised KV panels, code/`<code>` bg `#080D1B` |
| Accent (10%) | `#4F8CFF` | `--tl-color-thread-blue` (+ `--tl-focus-color` `#7FA9FF`) | **see reserved-for list** |
| Destructive | `#F06A6A` (text `#FF8585` dark) | `--tl-color-danger` | T3 type-to-confirm danger button, `tl-button--danger`, danger kebab item, error/unavailable-down state icon |

**Accent (`--tl-color-thread-blue` / focus ring) reserved for — explicit list:**
- Primary action buttons (`tl-button--primary`): Refresh, Generate export, the T2/T3 confirm primary
- Links (`tl-link`)
- `:focus-visible` ring on every interactive element (copy button, kebab trigger, modal buttons, table action links)
- Selected/active state stripe where present
- Info-status icon + the loading spinner stroke

Accent is **never** applied to body text, KV values, table cells at rest, or static decoration.

**Semantic status colors** (paired with shape/label, never alone), via `Presentation.status_modifier/1` → `tl-chip--*`: success `#3FD08F` (text `#5AE0A2`), warning `#F3B94C` (text `#F6C86B`), danger `#F06A6A` (text `#FF8585`), info Thread Blue (text `#9AB9FF`). The `data-status` left-stripe convention reuses these — zero new CSS for `row_status`.

**Diff cells (DATA-04 of D-22):** before/after attention may use ember `#FF8A5B` as a thin treatment only; meaning is carried by label ("Before"/"After") + position, not color.

## Truncation Rules (DATA-01, D-03/D-04/D-05)

Truncation is **server-side, middle, tail-biased** (`truncate_middle` with `:tail_min` guaranteeing ≥8 chars of tail). Forensic non-negotiable: the discriminating tail must always survive. **Kill CSS double-truncation** — remove `text-overflow: ellipsis` from `.tl-secondary-ref` (style.ex ~2490); CSS's only job is `overflow-wrap: anywhere` (wrap, never clip).

| Value type | Rule | Max |
|------------|------|-----|
| UUID / correlation id | middle | ~34 |
| ARN / `table.row` / `type/id` ActorRef | tail-weighted middle | — |
| Hash (SHA etc.) | middle | ~24 |
| File path | middle, **keep filename tail** | ~42 |
| Email | truncate localpart, **keep full domain** | — |
| URL | keep scheme+host head + last path segment tail | — |
| ISO timestamp | **never truncate** — show `human_time`, full ISO in `title` | — |
| KV snapshot value / diff before-after cell | middle + gated copy affordance (the core DATA-01 gap) | ~56 |

**Copy contract (D-02/D-06/D-07):** `data-tl-copy={ref.full}` on the `<code>`. Copy button gated by `Script.enabled?()` (`:if=`). Zero-JS recovery: when scripts disabled, render `ref.full` in `<code>` so select-all yields the exact value. Visible button text "Copy"; specificity lives in `aria-label` ("Copy correlation id", "Copy {table} capture command", …). Non-color-only `is-copied::after { content: "Copied" }` chip + reduced-motion-safe pulse + `:focus-visible` ring + optional visually-hidden `aria-live="polite"` SR region.

## Data-State Taxonomy (DATA-03, D-13..D-17)

Dispatch via `assign_async` / `<.async_result>`. The page author **must** branch ok-empty into `empty` (first-run) vs `no_data` (filters active) — `AsyncResult` cannot; and branch `:failed` reason into `permission` / `unavailable` / generic `error`. Preserve the server's typed reason (`:unauthorized`, `:source_down`, …) all the way to the view — never collapse to "something went wrong." No-color-alone via distinct icon **shape** per state.

The three load-bearing forensic distinctions must **never** collapse (D-16): permission = *exists, you can't see it*; no-data = *exists, your filter excluded it*; unavailable = *NOT a permissions issue — down/redacted/pruned*.

| State | Component | Role / focus | Icon shape | Heading | Next-action body |
|-------|-----------|--------------|-----------|---------|------------------|
| empty / first-run | `empty_state variant="never"` | `role=status` | history | No audit history yet | Run `mix threadline.gen.triggers`, migrate, then make a change. |
| loading | `loading_state/1` | `role=status` + `aria-busy` | spinner + text node | (text) Loading audit changes… | (resolves to a terminal state) |
| error | `error_state/1` | `role=alert` + focus `tabindex=-1` heading | alert | Could not load this timeline | Retry, then check logs. |
| stale | `stale_banner/1` | `role=status` (above data) | refresh / warning | — (strip) | Couldn't refresh — showing last known data from <timestamp>. Retry. |
| permission | `empty_state variant="permission"` | `role=alert` + focus rescue | lock / shield | You don't have access to this audit data | This data exists — your account needs `audit:read`. |
| no-data | `empty_state variant="no_data"` | `role=status` | funnel | No changes match these filters | Clear the filter or widen the time range. |
| unavailable — down | `empty_state variant="unavailable"` | `role=alert` | plug / cloud-off | Audit data is temporarily unavailable | This is not a permissions issue. Retry shortly. |
| unavailable — redacted | `empty_state variant="unavailable"` | `role=status` | eye-off | This value is withheld by policy | This is not a permissions issue. The record exists. |
| unavailable — pruned | `empty_state variant="unavailable"` | `role=status` | archive | Removed under retention on <date> | This is not a permissions issue. It was pruned by policy. |

> Icon note: brand-book.md:391 discourages lock/shield in *marketing imagery*; D-15 intentionally selects lock/shield for the functional **permission state icon** in the operator surface. This is a deliberate, scoped exception — functional state glyph, not decorative imagery. Reuse the `Icon` registry; add only `eye-off` (redacted) and `plug`/`cloud-off` (source-down) if missing.

## Copywriting Contract

Voice: plainspoken, sentence case, **no exclamation marks** (brand-book.md:405-419). Errors state what failed → why if known → next action, no blame.

| Element | Copy |
|---------|------|
| Primary CTA (coverage / data surfaces) | "Refresh" (coverage), "Generate export" (exports) |
| Empty state heading | No audit history yet |
| Empty state body | Run `mix threadline.gen.triggers`, migrate, then make a change. |
| No-data state | No changes match these filters. Clear the filter or widen the time range. |
| Error state | Could not load this timeline. Retry, then check logs. |
| Stale banner | Couldn't refresh — showing last known data from <timestamp>. Retry. |
| Permission state | You don't have access to this audit data. This data exists — your account needs `audit:read`. |
| Unavailable (down) | Audit data is temporarily unavailable. This is not a permissions issue. Retry shortly. |
| Unavailable (redacted) | This value is withheld by policy. This is not a permissions issue. The record exists. |
| Unavailable (pruned) | Removed under retention on <date>. This is not a permissions issue. It was pruned by policy. |
| Copy affordance | Button "Copy" → "Copied" (no exclamation); `aria-label` carries specificity; `title` carries the raw full value |
| Destructive confirmation (T3 redact) | "Redact this audit value" — type the change id `<id>` to confirm. Danger button: "Redact value — this cannot be undone". |
| Destructive confirmation (T3 prune now) | "Prune records now" — type the policy name `<name>` to confirm. Danger button: "Prune now — removes matching records permanently". |
| Destructive confirmation (T2 apply policy) | Modal names the object + states consequence; danger button "Activate — prunes records older than 90 days" (describe the consequence, never "Continue"). Cancel = `focus_first`. |

## Actions & Destructive Confirmation (DATA-04, D-18..D-21)

**Placement:** per-row kebab (`dropdown/1`) is the default (D-18); collapse to single inline `button/1` only for a lone T1 action. Destructive items last, after a `divider/1`, non-color-alone danger cue + `tl-button--danger`. Hover-reveal rejected (dies on touch). **No bulk multi-select** (D-19) — never bulk redact/prune.

| Tier | Severity | Mechanism |
|------|----------|-----------|
| **T1 direct** | reversible / additive (generate export, evidence ops) | plain `phx-click` + `phx-disable-with` + success toast — no modal |
| **T2 confirm modal** | reversible-but-wide (apply / activate retention policy) | `modal/1` naming object + consequence; Cancel = `focus_first`; danger button describes consequence |
| **T3 type-to-confirm** | irreversible (**redact** a value, **prune now**) | `modal/1` + `<form phx-submit>`; operator types the object's **own variable identifier** (change id / policy name) — never a constant like "DELETE" |

**T3 server-side enforcement (the load-bearing fix, D-21 — today's prune is client-only `data-confirm`, delete it).** Every irreversible `handle_event`, independent of any client signal, must: (1) re-fetch the **canonical** token from the DB at action time and `Plug.Crypto.secure_compare` against the typed value (never ship the token to the client); (2) re-check authorization in the event (`phx-value-id` is an untrusted claim) and scope-filter the query so a forged id fails closed; (3) **audit the destructive action itself** as an `AuditAction` (domain §9.3.4); (4) default path is refusal — fail closed on every mismatch.

## Flatten Rule (DATA-05, D-11/D-12)

**One card boundary per logical unit** (brand-book.md:348): a bordered/elevated surface marks exactly one repeated item or one self-contained panel; page *sections* (header, summary band, command bar) are plain `<section>`/`<header>` spaced by `--tl-gap-stack` (`--tl-space-6`) with thin divider/rail.

**Per-surface verdict (D-10):**
- Keep as `<table>`: Coverage (multi-row status), Retention history (streamed runs — drives `data_table` `stream:`).
- Keep as 2-col diff table (do **not** convert to KV): Policy/Redaction (Configured vs Deployed); fix collapse (`scope="row"` on field `<th>`, field name renders when stacked).
- Convert to `kv/1` `<dl>`: Transaction metadata, Actor detail header.
- Already-correct `<dl>` (leave + use as `kv` source): Row history snapshot.
- Keep as cards/list: Timeline, Evidence (`tl-record-card`), Exports (`tl-job` — normalize per-job `tl-param-list` → `kv`), Row-history timeline list.

**Coverage concrete fix:** delete the hand-rolled `tl-page__title/__lede/__meta` header inside the synthetic `tl-coverage-command` shell; use `page_header` in all three branches; demote/remove the shell so children (trust-rail, metric `tl-summary-grid`, remediation, table) become direct page-stack siblings; keep `tl-card--metric` tiles; delete dead `tl-coverage-command__*` CSS. **Add a regression test** that `refute`s any card-family class nested under another card-family class per rendered page.
