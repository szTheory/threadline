## Register procedure (every file in this plan)

Record the plan base: `git rev-parse HEAD > "$(git rev-parse --git-dir)/gsd-204-06-base"`.

1. `grep -n 'Structural debt:' <file>`; read only the enclosing function (Read with offset/limit from its `def` to its `end`).
2. Remove the `# Structural debt:` line and the disable directly below it. Restructure the function with early return, multi-clause pattern matching, `with`, or an extracted `defp` in the same module (D-13). Keep every branch, return value, error tuple, and log line. Do not reorder side effects.
3. `ASDF_ERLANG_VERSION=27.3 ASDF_ELIXIR_VERSION=1.17.3-otp-27 mix credo --strict <file>` must list no Nesting/CyclomaticComplexity issue; `mix compile --force --warnings-as-errors` clean.
4. Lower the matching check count in `@register` and `@ceiling` of test/threadline/credo_config_contract_test.exs (both are exact).
5. Run the file's tests (find them with `grep -rln '<ModuleName>' test`) plus `test/threadline/credo_config_contract_test.exs`.
6. Commit one file per commit: `refactor(204-06): flatten <function> in <path>`; the body lists check, function, and the technique used.

**HALT clause:** if a site cannot be flattened without changing behavior, apply the D-13 per-site fallback (re-register that one site with a `# Structural debt:` line naming a successor beyond v1.41, and keep the register exact), record it in the SUMMARY, and continue. Never bulk re-register, never use `disable-for-this-file` or `disable-for-lines`, never raise a Credo threshold, never edit a test assertion to fit new behavior, never bypass hooks. Never `git add .planning/`.
