# Phase 59 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Elixir library operator surface) |
| Preset | not applicable |
| Component library | Plain HTML/CSS (scoped) or Phoenix CoreComponents if injected |
| Icon library | Heroicons (standard for Phoenix LiveView) |
| Font | System UI fonts |

*Note: Since Threadline is an Elixir library, the UI relies on scoped CSS or standard Phoenix classes to avoid breaking the host application's styling.*

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing (e.g. diff field rows) |
| md | 16px | Default element spacing (e.g. between change cards) |
| lg | 24px | Section padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions: none

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | View Context |
| Empty state heading | No Changes Recorded |
| Empty state body | This transaction executed without producing any audited row changes. |
| Error state | Unable to Load |
| Not-found state | Transaction Not Found - The requested transaction ID does not exist or has been purged by the retention policy. |
| Destructive confirmation | N/A: Drill-down is read-only |

---

## Data Structure Presentation

* **Incident Bundle Header**: Displays `incident_bundle.action` metadata and actor details.
* **Changes**: Ordered list of `change_diff/2` representations.
* **Change Diff Visually**: For each `change`, display `op` ("INSERT", "UPDATE", "DELETE"), `table_name`, `captured_at`, and the list of `field_changes` showing `prior_state` / `before` vs `after`.
