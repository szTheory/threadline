<locked_checker_decisions>
Implements D-04 (mechanical gate policy — MODE-A absolute blockers + MODE-B ratchet floors).

1. **Determinism boundary:** the checker reads RAW scorecard JSON (Plan 02 rule 5) and computes ALL verdicts in Elixir. It NEVER launches a browser at assert time.
2. **MODE-A (absolute hard blockers, fail `ci.all` immediately, no grandfathering):**
   - WCAG contrast from `color_pairs`, dark + light independently: normal text 4.5:1, large text (font-size ≥24px OR bold ≥18.66px) 3:1, non-text/UI 3:1. Use the sRGB piecewise formula with gamma exponent 2.4 (Pitfall 4).
   - Conformance from `element_styles`: `border-radius` ∈ [3,4,6,8,12,999]px; `box-shadow` matches one of the 4 shadow token patterns; `transition-duration` ∈ [120,180,240]ms; `font-size` ∈ [12,13,14,15,16,20,24,32]px; spacing (margins/paddings captured) ∈ [4,8,12,16,20,24,32,40,48]px.
   - Each MODE-A violation emits a located, actionable, fix-carrying map (`:cell_id, :metric, :mode, :selector, :observed, :expected, :fix`). This set is the exact Phase-196 auto-apply whitelist.
   - If existing `/audit` pages surface MODE-A violations, apply the emitted nearest-token / nearest-passing-contrast fix (that IS MODE-A's remit — making the gate green via mechanical snaps is not scope creep). Given the v1.37/v1.38 WCAG-AA + token-parity work, expect near-zero.
3. **MODE-B (ratchet-floor, betterer-style seed):** type-size count, interactive-control count, card-nesting depth, scroll-cost/bp, distinct-accent-hue (Elixir does RGB→HSL + ±15° bucketing over `applied_colors`, saturation >20% to drop grays). Seed `mechanical_floors` from the first committed capture (floor = measured value per entry × metric × theme_bp), so no regression is possible at phase end; a future value worse than the seeded floor fails. The two structural metrics carry an absolute far ceiling: card-nesting depth >3 and distinct-accent-hue >3 fail regardless of floor — BUT any already-existing >3 violation is recorded as a grandfathered floor with a note (mirrors the tracked footgun entries) so `ci.all` is green at phase end while future worsening is blocked. Do not auto-fix MODE-B (structural — Phase 196/197 + human).
4. **Threshold provenance:** MODE-A constants are LOCKED module attributes pinned by the meta-test. MODE-B floors live in the ledger `mechanical_floors` block, monotonic via the Plan 01 guard. No Linear number is ever committed as a CI threshold.
</locked_checker_decisions>
