# Phase 147 Plan: Token & Asset Source System

## Goal

Create source-controlled implementation primitives.

## Requirements

- BRAND-TOKENS-01
- BRAND-LOGO-01

## Tasks

1. Define raw and semantic tokens in JSON and CSS.
2. Include dark, light, state, focus, status, code, callout, typography, spacing, radius, border, and modest elevation roles.
3. Create editable SVG logo, mark, monochrome, favicon, and social-card assets.
4. Keep assets transparent-background-safe, accessible, simple, and small.

## Verification

- JSON parses.
- SVGs parse as XML.
- Representative text/background pairs meet WCAG AA.
- Assets stay SVG-only and source-control friendly.
