<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> mounted shell DOM | Playwright interacts with server-rendered nav, Home launchers, focus state, and theme controls. |
| Browser -> theme route | Theme controls submit to the server-owned `{base_path}/theme` POST form and must stay CSRF-backed. |
| Browser -> adjacent operator pages | Adjacent routes are visited only to prove shell invariants and must not widen page-content scope. |
| Browser -> Home launchers | EF1 row-history and EF4 correlation launchers accept untrusted form input and must validate before navigation. |

## ASVS L1 Baseline

ASVS L1 applies. This plan creates browser evidence only; any finding that feature gates are client-only, theme state mutates outside the CSRF form, launcher validation is bypassed, focus/overflow blocks keyboard/mobile operators, or shell/Home text is inserted through unsafe HTML blocks Plan 02 until mitigated.

| ASVS Area | Plan Mapping |
|-----------|--------------|
| V4 Access Control | Browser assertions must see feature-gated destinations only when server-rendered by existing auth assigns. |
| V3 Session Management / V6 Cryptography | Theme assertions must preserve server-resolved theme state and CSRF POST behavior. |
| V5 Validation, Sanitization, and Encoding | Home launcher tests must verify local validation and canonical route navigation. |
| V14 Configuration | No new browser framework, visual-regression SaaS, root UI dependency, or production development route is added. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-183-01 | Information Disclosure / Elevation of Privilege | Feature-gated shell destinations | mitigate | Browser tests assert enabled destinations from server-rendered nav and Plan 02 keeps groups absent when disabled. |
| T-183-02 | Tampering | Theme picker | mitigate | Browser tests assert native radios and selected state while source contracts keep POST plus CSRF and no inline event handlers. |
| T-183-03 | Tampering | EF1 row-history and EF4 correlation launchers | mitigate | Browser tests assert blank-input alert copy and canonical route navigation for valid flows. |
| T-183-04 | Denial of Service | Mobile/focus/overflow shell | mitigate | Browser tests assert visible focus and no horizontal overflow at 320px and after nav open. |
| T-183-05 | Tampering / XSS | Shell/Home visible copy | mitigate | Browser tests rely on HEEx-rendered text and Plan 02 source contracts forbid manual HTML-string shell/Home rendering. |
| T-183-SC | Tampering | Package installs | accept | Phase 183 installs no new npm, Hex, pip, or cargo packages; existing Playwright/Phoenix dependencies are reused. |
</threat_model>
