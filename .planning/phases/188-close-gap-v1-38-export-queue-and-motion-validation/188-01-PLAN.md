## Trust Boundaries

| Boundary | Description |
|---|---|
| persisted ExportJob.query_params -> worker | Stored string-keyed params may be stale, malformed, or tampered before replay. |
| worker -> Threadline.Query/export stream | Parsed filters control which audit rows leave storage through an export file. |
| LiveView affordance -> ExportJob row | Keyboard/pointer UI creates a durable job, but UI visibility is not the security boundary. |
