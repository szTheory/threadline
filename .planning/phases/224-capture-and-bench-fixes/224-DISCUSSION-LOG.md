## Test design (researched only)

Recommended and adopted:
- Extend `trigger_rerun_test.exs` with the deterministic regression.
- A new DB-backed property file and a new run-sequence generator support module.
- An orphan check against `pg_proc` scoped to the storage schema, independent of `Naming`.
- `@max_runs 20`, cleanup with `try/after` on each iteration.
- Mutation controls run by hand and recorded.

Orchestrator corrections to the researcher's output:
- A partial rollback keeps the trigger on the rerun's per-table function. It does not revert to
  the global function.
- With first-run-only emission, a partial rollback prints no "kept" WARNING.

Left to the planner: whether the regression's full-chain case goes through `Ecto.Migrator` for
literal fidelity to `mix ecto.rollback --all`.
