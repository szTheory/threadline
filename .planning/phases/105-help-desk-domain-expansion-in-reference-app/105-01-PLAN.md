  <action>
Generate via `cd examples/threadline_phoenix && mix ecto.gen.migration create_help_desk_tables`.

Create tables with **`binary_id` primary keys** and `references(..., type: :binary_id)`:

1. **organizations** — `slug` (string, null: false), `name` (string, null: false), `timestamps(type: :utc_datetime)`. `unique_index(:organizations, [:slug])`.

2. **org_memberships** — `organization_id` FK → organizations, `user_id` (string, null: false), `role` (string, null: false) storing `"agent"` or `"support"`. `unique_index(:org_memberships, [:organization_id, :user_id])`.

3. **agents** — `organization_id` FK, `user_id` (string, null: false), `display_name` (string, null: true). `unique_index(:agents, [:organization_id, :user_id])`.

4. **tickets** — `organization_id` FK, `number` (integer, null: false), `status` (string, null: false, default `"open"`), `assignee_id` FK → agents (on_delete: :nilify_all or :restrict per Ecto best practice), `closed_at` (:utc_datetime, null: true). `unique_index(:tickets, [:organization_id, :number])`.

5. **ticket_replies** — `ticket_id` FK → tickets, `body` (text, null: false) for public reply text, `internal_note_body` (text, null: true) for sensitive note column, `timestamps(type: :utc_datetime)`.

Do not add Threadline audit tables — those come from existing `mix threadline.install` migrations.
  </action>

Create five schema modules under `lib/threadline_phoenix/help_desk/`:

- `ThreadlinePhoenix.HelpDesk.Organization`
- `ThreadlinePhoenix.HelpDesk.OrgMembership`
- `ThreadlinePhoenix.HelpDesk.Agent`
- `ThreadlinePhoenix.HelpDesk.Ticket`
- `ThreadlinePhoenix.HelpDesk.TicketReply`

Each schema MUST include:
```elixir
@primary_key {:id, :binary_id, autogenerate: true}
@foreign_key_type :binary_id
```

Associations:
- Organization `has_many` memberships, agents, tickets
- OrgMembership `belongs_to` organization
- Agent `belongs_to` organization; `has_many` tickets as assignee
- Ticket `belongs_to` organization, `belongs_to` assignee (Agent), `has_many` ticket_replies
- TicketReply `belongs_to` ticket

Changesets:
- `Organization`: cast `slug`, `name`; validate_required; unique_constraint slug
- `OrgMembership`: cast `role` only; set `organization_id` and `user_id` in context API later — for changeset validate `role` in `["agent", "support"]`
- `Agent`: cast `display_name`; require `user_id` + `organization_id` set outside cast
- `Ticket`: cast `number`, `status`, `closed_at`; require `organization_id`; unique_constraint `[:organization_id, :number]`
- `TicketReply`: cast `body`, `internal_note_body`; require `ticket_id`

Add minimal `ThreadlinePhoenix.HelpDesk` module file that only `alias`es the five schemas (or defer full API to Plan 02 — file may be a stub with `@moduledoc` pointing to Plan 02).
  </action>
