## Trust Boundaries

| Boundary | Description |
|---|---|
| Host router config to mounted LiveView | Host-controlled literal `theme:` option affects rendered CSS lane. |
| Operator surface CSS to host page | Mounted surface must remain scoped and must not modify host `<html>` or `<head>`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-166-01 | Tampering | `theme:` router option | mitigate | Compile-time literal allowlist `:dark | :light | :system`; invalid values raise before routes compile. |
| T-166-02 | Information disclosure | Host page integration | mitigate | No JS, localStorage, cookies, or head injection; theme is static host config rendered only as scoped `data-tl-theme`. |
| T-166-03 | Denial of service | CSS contract/test mismatch | mitigate | `style.ex` and `style_contract_test.exs` change in the same wave; focused tests run before summary. |
</threat_model>
