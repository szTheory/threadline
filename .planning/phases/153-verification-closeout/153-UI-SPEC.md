## Spacing Scale

Active Phase 153 spacing uses only the approved 4/8 scale values below:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Fine gaps, nav grid gaps, small separators |
| sm | 8px | Compact element spacing, inline padding |
| md | 16px | Default element spacing, small panels |
| lg | 24px | Section internals, sidebar padding, medium gaps |
| xl | 32px | Layout gaps, hero actions, sidebar logo rhythm |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level section padding |

Existing artifact exceptions only, do not use for new Phase 153 UI: committed brandbook tokens or CSS may retain `sm-plus: 12px`, `md-plus: 20px`, legacy `2xl: 40px`, and `5xl: 80px` where already present in `brandbook/` artifacts. Interactive targets must keep at least 44px height; `999px` is allowed only for pill/counter radius, not layout spacing.

## Typography

Phase 153 must not introduce new type roles. New verification/closeout UI text, if any, uses only these roles:

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 600 | 1.4 |
| Heading | 20px | 600 | 1.2 |
| Display | 32px | 600 | 1.15 |

Existing brandbook exceptions may remain unchanged: nav/meta tokens at 12-13px, hero `h1` clamp, and section heading clamp are part of the committed static brandbook contract. Do not add new font families, negative letter spacing, exclamation-heavy promotional copy, or extra weights.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0B1020` | Brandbook background, dark infrastructure field, screenshot first viewport |
| Secondary (30%) | `#141B2D` | Panels, sidebar, cards, static surfaces |
| Accent (10%) | `#4F8CFF` | Text links, primary CTA, selected path, active evidence links |
| Destructive | `#F06A6A` | Destructive actions only; none expected in Phase 153 |

Accent reserved for: brandbook text links, `button-primary`, active/selected paths, and verification evidence links. Signal Cyan `#4EDFD1` is reserved for connected-flow emphasis, score/evidence highlights, and non-destructive positive signal states. Light documentation surfaces use `#F7F9FC` background, `#0F1728` text, and `#1557C0` accent; use `logo-primary-light.svg` on README/GitHub/light documentation surfaces.

## Interaction Contract

| Interaction | Required Behavior |
|-------------|-------------------|
| Keyboard navigation | `Skip to content` becomes visible on focus; sidebar anchors and hero buttons are keyboard reachable. |
| Focus states | Links and controls use the existing `--tl-focus-ring`; no outline removal without replacement. |
| Hover states | Links move from `--tl-color-accent` to `--tl-color-accent-strong`; sidebar links use `--tl-color-surface-hover`. |
| Touch targets | Buttons keep `min-height: 44px`; mobile buttons are full-width and do not resize surrounding layout on hover/focus. |
| Local navigation | Anchor links stay local to the brandbook page or committed local files; do not add external network dependencies. |
| Evidence review | Verification output must distinguish PASS, FAIL, and deferred scope in text, not color alone. |
