<objective>
Gap closure for a regression found after landing (PR #55, merge ff346b1a). On main, Release run 36319430805 failed in `sync-release-pr-pins`: the toolchain-first sparse checkout from plan 216-03 left the workspace sparse, and the following release-branch checkout produced a tree with only `.tool-versions` (git 2.55: `git sparse-checkout disable` is a no-op when sparse was enabled through plain `core.sparseCheckout` config, so the plan 03 assumption A2 failed on the runner's git). `publish-hex` and `smoke-published` use the same shape and would fail at publish time, so release PR #56 (0.11.1) must not merge until this lands.

Fix: isolate the toolchain checkout in `path: .toolchain-pin` and point setup-beam at `.toolchain-pin/.tool-versions`. The orchestrator already validated this in Docker with git 2.55.0 (`$CLAUDE_JOB_DIR/tmp/fix.sh` shape): root checkout gets `mix.exs`, pin dir is gone, `core.sparseCheckout` unset. Confirmed in actions/checkout v5 `src/git-directory-helper.ts`: a root with no `.git` has its contents removed before the clone.
</objective>
