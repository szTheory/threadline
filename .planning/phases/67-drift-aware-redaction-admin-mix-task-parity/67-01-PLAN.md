<objective>
Create the load-bearing Phase 67 shared reconciliation core: one pure-stdlib module that normalizes configured redaction policy, fetches deployed trigger SQL from PostgreSQL catalogs, parses only known Threadline-generated redaction fragments conservatively, and classifies each table into `config_matches_deployed`, `drift_detected`, or `could_not_introspect`.

Purpose: both the new LiveView and `mix threadline.policy.show` need the same facts and the same safety posture. Getting the parser, diffing rules, and summary shape right once at the shared layer prevents semantic drift across surfaces and keeps ambiguity fail-closed.

Output: one extracted shared config loader, one new shared presenter, plus focused parser tests and one repo-backed catalog test. No Phoenix gating in this plan.
</objective>

## New module responsibility

- extract current `trigger_capture` loading/normalization out of `Mix.Tasks.Threadline.Gen.Triggers` into a shared loader
- re-validate every configured table entry with `Threadline.Capture.RedactionPolicy.validate!/1`
- normalize configured per-table redaction settings from `Application.get_env(:threadline, :trigger_capture, ...)`
- fetch deployed trigger metadata per table from catalogs
- validate that parsed function bodies are the expected Threadline-owned `plpgsql` trigger shape before trusting fragment matches
- parse conservative deployed redaction shape from `pg_proc.prosrc`
- compute exact set/placeholder diffs
- apply canonical section ordering and alphabetical intra-section ordering once in the shared layer
- produce grouped results in locked section order:
  1. `drift_detected`
  2. `could_not_introspect`
  3. `config_matches_deployed`

Recommended public API:

```elixir
Threadline.Policy.RedactionPresenter.build(repo: repo, schema: "public")
```

Return shape should be machine-friendly and additive:

```elixir
%{
  summary: %{drift_detected: n, could_not_introspect: n, config_matches_deployed: n},
  tables: [%{table: "...", status: :drift_detected, configured: ..., deployed: ..., diff: ..., hint: ...}],
  grouped: [drift_detected: [...], could_not_introspect: [...], config_matches_deployed: [...]]
}
```
