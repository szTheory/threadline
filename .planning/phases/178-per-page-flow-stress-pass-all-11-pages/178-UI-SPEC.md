# Phase 178 — UI Design Contract

> Visual and interaction contract for the per-page & flow stress pass (all 11 operator pages). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Phase nature:** This is an **integration / audit / fix** pass, not a greenfield UI phase. The 11 pages are already assembled from the audited primitives (173), form controls (174), shell/nav (175), data-display components (176), and groups/meta-components (177). Phase 178 stresses those assembled pages under ugly data across the full matrix, eliminates 11 named footgun classes, fixes the transaction centering bug, and folds in SEED-005 (shared shell + reconnect banner mount + `data-tl-mutating` wiring). It introduces **no new visual tokens**; it consumes and guards the existing `--tl-*` / `brandbook/tokens.{json,css}` contract. The contract below therefore reflects the **established, frozen-parity design system** that every page must hold to — the checker validates against it, the executor preserves it, and the footgun detectors assert against it.

## Spacing Scale

The operator surface uses the existing `--tl-space-*` token scale (4px base step). Phase 178 must not introduce raw spacing; every page spacing decision resolves to one of these tokens or a semantic gap token. The "misalignment / chopped padding / inconsistent spacing" footgun detector (PAGE-02 #6) asserts against this scale.

| Token | Value | Usage |
|-------|-------|-------|
| `--tl-space-1` | 4px | Icon gaps, inline padding, `gap=tight` |
| `--tl-space-2` | 8px | Compact element spacing, `--tl-gap-inline` |
| `--tl-space-3` | 12px | Control inner padding |
| `--tl-space-4` | 16px | Default element spacing, `--tl-gap-stack` |
| `--tl-space-5` | 20px | Card inner padding |
| `--tl-space-6` | 24px | Section padding |
| `--tl-space-8` | 32px | Layout gaps, `--tl-gap-section` |
| `--tl-space-10` | 40px | Major block separation |
| `--tl-space-12` | 48px | Major section breaks |
| `--tl-space-16` | 64px | Page-level spacing |
| `--tl-space-20` | 80px | Top-level page rhythm |

Semantic gap tokens (added in 177, used by `UI.stack/1` / `UI.cluster/1`): `--tl-gap-inline` (8px), `--tl-gap-stack` (16px), `--tl-gap-section` (32px).

**Exceptions:** none new this phase. Inter-child spacing must flow through `UI.stack/1` / `UI.cluster/1` flexbox `gap` over the gap tokens (no raw child margins — GROUP-01 / D-02 carryover). The PAGE-03 fix adds `justify-self: center` to `.tl-container` (positioning, not a spacing token) keeping `max-width: 1000px`.

## Typography

Existing `--tl-font-size-*` / `--tl-font-weight-*` / `--tl-line-height-*` scale. Phase 178 reuses it as-is; the "unreadable dark/light text" and "same-color text-on-background" footgun detectors (PAGE-02 #10/#11) assert WCAG AA contrast against these roles in both themes via the in-repo `contrast_ratio/2` engine.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 (regular) | 1.5 |
| UI / control | 15px | 400 (regular) | 1.5 |
| Label / caps | 14px | 600 (strong) | 1.4 |
| Heading (`<h2>` detail header) | 20px | 600 (strong) | 1.2 |
| Title / page `<h1>` | 24px | 600 (strong) | 1.2 |
| Display | 32px | 600 (strong) | 1.2 |
| Small / meta | 13px | 400 (regular) | 1.4 |
| XS / dense | 12px | 400 (regular) | 1.4 |
| Mono (code/IDs/log/JSON) | 13–15px | 400 (regular) | 1.5 |

**Weights in active use:** 400 (regular) for body/UI/data, 600 (strong) for headings/labels/emphasis. (500 medium exists in the token set but is reserved; do not introduce new weight usage this phase.)

**Heading hierarchy contract (load-bearing for footgun #8 "missing tab active-state" and the page-header group):** exactly one `<h1>` per page (the `page_header` title); drill-down detail headers use `<h2>` via `UI.detail_header/1` (D-175-03 carryover). Do not add competing `<h1>`s when stressing pages.

## Color

Operator surface is dark-first (brand-primary), with a parity-locked light lane and a `system` mode. The 60/30/10 split below is expressed in `--tl-color-*` tokens; values shown are the **dark** lane (the default and brand), with the light-lane equivalent governed by the same token name. Footgun detectors #10/#11 verify every text/background pairing meets WCAG 2.2 AA in **both** lanes.

| Role | Value (dark lane) | Usage |
|------|-------|-------|
| Dominant (60%) | `#0B1020` threadline-black / `#141B2D` graphite | Page background, base surfaces (`--tl-color-bg` / `--tl-color-surface`) |
| Secondary (30%) | `#1B253A` surface-raised / `#202B42` surface-hover | Cards, panels, nav, raised regions, hover states |
| Accent (10%) | `#4F8CFF` thread-blue (`--tl-color-accent`) | See reserved-for list |
| Destructive | `#F06A6A` danger / `#FF8585` danger-dark-text | Destructive actions only (prune; redact deferred) |

**Accent reserved for** (never "all interactive elements"):
- Primary action buttons (e.g. the prune confirmation submit, save-view submit)
- Active / current navigation + tab state (paired with a non-color cue — shape/weight/underline)
- Focus ring (`--tl-focus-ring`, `#7FA9FF`) on keyboard-focused controls
- Inline links / copyable-ID affordances and the selected/`aria-current="page"` marker
- Stitch-blue `#4781E6` is **logo-mark exclusive** (the arc) — must NOT leak into operator UI; the interface accent stays `#4F8CFF`.

**Status / semantic colors** (never the sole signal — always paired with an icon shape, label, or position per the no-color-alone rule, footgun #10 territory):
- Success `#3FD08F` (dark text `#5AE0A2`) — covered / completed
- Warning `#F3B94C` (dark text `#F6C86B`) — stale banner, drift detected, reconnect banner tint
- Danger `#F06A6A` (dark text `#FF8585`) — error states, destructive confirmation
- Info `#4F8CFF` (dark text `#9AB9FF`) — informational callouts

**Reconnect / offline state (SEED-005):** warning-tinted `role="status"` banner mounted once in the shared shell above `#tl-main`, keyed off `.threadline-ui.phx-loading` / `.threadline-ui.phx-error` (never `<body>`, never the legacy `.phx-disconnected`). `[data-tl-mutating]` controls render `opacity: 0.55; pointer-events: none` while disconnected.

## Copywriting Contract

Phase 178 fixes copy only where a footgun fix touches it (brand voice: plainspoken, sentence case, no exclamation marks, name the object + consequence, no blame). The **systematic** microcopy / IA / banned-vocabulary / domain-language sweep is **Phase 179 — do not pre-empt it.** Copy below is the contract for the states each stressed page must present.

| Element | Copy |
|---------|------|
| Primary CTA (destructive) | "Prune now" — confirmed by typing the policy name (`secure_compare` server-enforced) before the irreversible prune runs |
| Primary CTA (save view) | "Save view" / "Delete view" (timeline) |
| Empty state — first run (`never`) | Heading names the absent entity ("No row history yet" / "No audit transactions yet"); body states the next step (e.g. "Changes appear here as audited tables are mutated.") — distinct icon shape from filtered-empty |
| Empty state — filtered (`no_data`) | "No results match these filters" + a clear "Clear filters" affordance; visually distinct from first-run empty (different icon shape, not just color) |
| Loading state | `role="status"`, `aria-busy`, spinner + visible text node ("Loading…" / entity-specific) — must announce, not just spin |
| Stale state | Warning-tinted `stale_banner` above the data (never replacing it): "Showing data as of {as_of}" + Retry — `role="status"` |
| Error state | Says what happened + how to recover (e.g. "Couldn't load transactions. Retry."); `error_state` icon shape distinct from empty; never blames the operator |
| Permission denied | Distinguished from no-data AND from unavailable-data: lock icon shape, "You don't have access to this." — explicitly NOT a "no data" message |
| Unavailable data | cloud-off / source-down icon shape; copy states "this is not a permissions issue" to disambiguate from permission-denied |
| Reconnect banner | Warning-tinted `role="status"`: connection-lost / reconnecting message; actions disabled while shown |
| Pagination caption | `role="status" aria-live="polite"` range caption; honest "Showing latest N" / "10,000+" cap; hides at zero results, disables (not hides) at boundaries |

**Destructive actions this phase:** only **prune** (`prune_now`) is live — server-enforced `secure_compare(typed, server-canonical policy name)` + authz re-check + scope fail-closed + audit-the-action; confirmation names the object and the irreversible consequence. Redact is **deferred** (no runtime backend — [176-05]). No bulk/multi-select destructive actions (rejected D-176-19).

## Interaction & Footgun Contract (PAGE-02)

This phase's load-bearing visual/interaction contract is the **elimination of 11 named footgun classes**, guard-first (write the failing detector, watch it fail, fix to green — each becomes a permanent CI assertion). The checker should treat these as the interaction acceptance criteria.

| # | Footgun class | Contract / detector |
|---|---------------|---------------------|
| 1 | Scroll traps (nested-scroll, sticky covers content) | No nested scroll containers trap; sticky elements never occlude content (`scroll-margin-top` / `scroll-padding-top` reconciled, `overscroll-behavior: contain`, `100svh`) |
| 2 | Modal/drawer hidden behind scrim or floating wrong | Z-token ascending order guard + `elementFromPoint` hit-test — overlay sits above scrim, scrim above page |
| 3 | Focus not entering/restoring from overlays | `JS.focus_first` / `phx-mounted` present (Tier A) + `toBeFocused` on open / focus returns to trigger on close (Tier B) |
| 4 | Escape / click-outside inconsistency | Esc and scrim-click both dismiss; focus returns to the invoking control |
| 5 | Hover/focus affordance on non-interactive elements | Non-interactive elements expose no `cursor: pointer` / hover / focus affordance |
| 6 | Misalignment / chopped padding / inconsistent spacing | Spacing resolves to `--tl-space-*` / gap tokens only; `boundingBox` within-viewport at 320–1440 |
| 7 | Disabled-looks-enabled (and enabled-looks-disabled) | Disabled controls carry real `disabled`/`aria-disabled` + `not-allowed` cursor + reduced-opacity token; enabled controls never look disabled |
| 8 | Missing tab / nav active-state | `aria-current="page"` / `aria-selected` distinct background **plus** a non-color cue (weight/underline/shape) |
| 9 | Weird pagination | `UI.pager` disabled-at-edge, hide-at-zero, honest cap caption; no dead/duplicate controls |
| 10 | Unreadable dark/light text | `contrast_ratio/2` WCAG AA on every text/bg pairing, **both** themes |
| 11 | Same-color text-on-background | Composited-tint contrast check (alpha-aware) catches text matching its background |

**PAGE-03 — transaction centering:** add `justify-self: center` to `.tl-container` (`style.ex:675`), keep `max-width: 1000px`. Guard: Tier A asserts the rule is present (prevents silent revert to bare `margin: 0 auto` on a grid item); Tier B asserts the content bounding box is horizontally centered at 1024 + 1440 (`|center_x − viewport/2| ≤ tolerance`). Inner `tl-short-content` alignment (D-09b) is opportunistic, not required for acceptance.

**Motion:** all motion stays within the existing motion-token contract (`--tl-motion-fast` / `--tl-motion-base` = 180ms); the reduced-motion blanket (`style.ex:3868`) already collapses transitions — new/stressed pages inherit it. No new keyframes. (Formal motion compliance sign-off is Phase 180.)

## Verification Tier Contract (PAGE-01)

The contract is **explicit about what each tier proves** — a green suite must never imply all ~3,465 matrix cells were eyeballed:

- **Tier A (Elixir `render_component` / `rendered_to_string` DOM + CSS-source assertions, every PR):** proves the **full structural cartesian** (~1,155 page × path × theme × viewport cells render, carry the right `data-state`, don't loud-fail, emit the right keyboard / reduced-motion / reconnect CSS hooks).
- **Tier B (Playwright real-engine, on `verify-example-browser`):** proves a **representative high-signal sample** (~66 cells): per page 320 floor + 1440 ceiling, happy + worst-case (error/empty), dark + light, plus one keyboard-only, one reduced-motion, one reconnect spec.
- **Never pixel-diff** (deterministic, baseline-free — confirmed preference).
- **Ledger ratchet:** the 11 reserved `page.<x>.reserved` entries (score 35, owner 178) become real fixture-backed path stories raised toward `target_score: 90` (upward-only); `footgun.transaction-page-left-push-desktop` (score 25 → 90) is the PAGE-03 peg; the two existing baselines (`page.home.happy`, `page.timeline.empty`, score 62) get raised too. `DESIGN-SYSTEM.md` projection asserted fresh.
- **Residual manual ≈ zero:** only sub-pixel optical balance and "focus landed somewhere *sensible*" are an optional, non-blocking spot-check note — not a UAT gate (0-human-UAT goal).
