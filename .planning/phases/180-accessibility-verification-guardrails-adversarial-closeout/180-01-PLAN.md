## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser to operator LiveView | User input, focus movement, and opened UI state cross from an untrusted client into authenticated LiveView routes. |
| Stress route auth gate | Stress stories are development/test verification surfaces and must remain fail-closed outside allowed environments. |
| Accessibility evidence | Browser assertions prove UI affordances, not authorization or data integrity. |
