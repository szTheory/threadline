Complete `transaction/3` body:

1. After actor validation, call `repo.transaction(fn -> ... end)` and normalize outer return to `{:ok, result} | {:error, reason}` (Ecto may return bare value on success inside — match Blog pattern)

2. **Inside transaction, before callback:**
   - If `actor_ref` non-nil: encode JSON via `ActorRef.to_map/1` + `Jason.encode!/1`, run `repo.query!("SELECT set_config('threadline.actor_ref', $1::text, true)", [json])`
   - If nil actor allowed: skip GUC set

3. **Run callback** `fun.()` — propagate `repo.rollback/1` on domain failure

4. **If `:action` resolved:**
   - Build `action_opts` with `repo: repo`, `actor: actor_ref`, plus `correlation_id`, `request_id`, `job_id` from resolved opts
   - Call `Threadline.record_action(action_name, action_opts)`
   - On `{:ok, %AuditAction{id: action_id}}`: `repo.update_all` on `AuditTransaction` where `txid == fragment("txid_current()")`, set `action_id` and `meta: transaction_meta` (from `:transaction_meta` opt, nil allowed)
   - If update count != 1: `repo.rollback(:missing_audit_transaction_for_link)`
   - Fetch `audit_transaction_id` via `repo.one!` query on `AuditTransaction` where `txid == fragment("txid_current()")`, select `id`

5. **If no `:action`:** still fetch `audit_transaction_id` after callback if domain write produced capture row (same txid query)

6. **Return envelope (D-111-02):**
   - If callback result is map: `Map.put(result, :audit_transaction_id, id)`
   - Else: `%{result: result, audit_transaction_id: id}`

Add `# doc: start: audit-transaction-helper` / `# doc: end: audit-transaction-helper` markers around a canonical example in moduledoc or function doc (multi-line comment block matching Blog marker style).

Moduledoc MUST include table: capture-only vs correlation-ready, forbidden callback ops (`set_config`, `record_action`, nested transaction), nil-actor policy, pointer to `Threadline.Query` strict correlation_id.
