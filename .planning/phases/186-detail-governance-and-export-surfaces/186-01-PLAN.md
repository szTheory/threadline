<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser to LiveView params | `:id`, `:table`, `:record_id`, `:kind`, and `as_of` route/query values are untrusted. |
| LiveView to repo callbacks | Scope query, row lookup, and transaction lookup callbacks gate host-owned data access. |
| Detail overlay to browser focus | Drawer close, Escape, and focus return affect keyboard and assistive-technology users. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-186-01 | Tampering | `RowHistoryComponent` route/query params | mitigate | Keep existing path encoding and as-of validation tests; continue scope-query filtering before rendering row history. |
| T-186-02 | Denial of Service | `ActorLive` actor-kind parsing | mitigate | Replace unbounded atom creation with a private allowlist parser and invalid-kind test. |
| T-186-03 | Information Disclosure | Detail copy/ref rendering | mitigate | Preserve full-value copy target tests and scoped hiding tests for transaction, row history, and actor pages. |
| T-186-04 | Spoofing | Row-history drawer dialog semantics | mitigate | Use `UI.drawer/1` so role/name, visible close, Escape, focus entry, and focus return are handled by shared overlay behavior. |
| T-186-SC | Tampering | Package/dependency surface | mitigate | No package-manager install or dependency file edits are part of this plan. |
</threat_model>
