<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser to export LiveView | Timeline/Evidence export context query params and queue events are untrusted. |
| Browser to HTTP export controller | `/exports/download/:job_id` is direct HTTP and must remain actor/status/expiry authorized. |
| Feature-gate assigns to rendered controls | Evidence, exports, coverage, and policy gates decide which links and buttons can exist. |
| Policy presenter to browser | Redaction status can reveal posture but must not expose samples or destructive operations. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-186-05 | Spoofing | Completed export links | mitigate | Real links are focusable and no disabled-looking attributes remain; controller tests enforce authorization and status. |
| T-186-06 | Tampering | Export queue event | mitigate | Keep server-side validation for enabled exports and valid Timeline context; tests forge denied/invalid queue events. |
| T-186-07 | Information Disclosure | Direct export downloads | mitigate | Preserve `ExportController` actor ownership, status, expiry, and storage tests. |
| T-186-08 | Elevation of Privilege | Feature-gated Evidence/Redaction/Exports controls | mitigate | Omit gated controls from disabled surfaces and preserve UnsupportedView shell gates. |
| T-186-09 | Tampering | Redaction runtime actions | mitigate | Do not render runtime destructive controls; tests assert absence while presenter posture remains visible. |
| T-186-SC | Tampering | Package/dependency surface | mitigate | No package-manager install or dependency file edits are part of this plan. |
</threat_model>
