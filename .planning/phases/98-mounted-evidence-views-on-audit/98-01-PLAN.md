## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Mounted route params -> evidence read helpers | User-controlled query params must narrow the existing proof surface safely without creating a new query model. |
| Mounted UI -> proof semantics | The LiveView must translate proof facts without mutating verdict meaning or overclaiming unsupported territory. |
| Denied capability -> operator copy | Unsupported access must stay explicit so support-scoped sessions do not gain accidental silent visibility. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-98-01 | Tampering | `EvidenceLive` query-param parsing | mitigate | Keep URL params bounded to subject, subject-ref JSON, and latest/history modes; reject invalid shapes and reuse existing API validators. |
| T-98-02 | Information disclosure | mounted evidence rendering | mitigate | Drive all reads through `Threadline.Evidence` / `Proof` instead of direct schema queries so mounted output cannot drift into broader evidence exposure. |
| T-98-03 | Repudiation | unsupported / empty mounted states | mitigate | Render explicit unsupported and empty-state copy with CLI fallback instead of hiding the route or implying claims the mounted tree cannot prove. |
</threat_model>
