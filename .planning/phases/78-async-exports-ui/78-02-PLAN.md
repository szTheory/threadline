    6. Ensure only one node performs this by using Postgres advisory locks, exactly like `Threadline.Retention.Pruner`.
  </action>

    1. In `Threadline.OperatorSurface.Router`, under the `exports` scope, add a new route: `get "/download/:job_id", ExportController, :download`.
    2. In `ExportController`, implement `download/2`. 
    3. Fetch the `ExportJob` by `:job_id`. Verify the requesting actor matches the `actor_ref` stored on the `ExportJob` to prevent IDOR.
    4. Check if `status == "completed"` and `file_path` is present.
    5. Call `Threadline.Storage.path(job.file_path)`. Do NOT use `Threadline.Storage.get/1` as it pulls the file entirely into memory.
    6. If it returns `{:ok, absolute_path}`, use `Plug.Conn.send_file(conn, 200, absolute_path)` after setting the appropriate `Content-Disposition` header. If it returns `{:error, reason}`, fallback or return an error. This ensures massive CSVs are downloaded safely via underlying OS mechanisms without OOMing the node.
  </action>
