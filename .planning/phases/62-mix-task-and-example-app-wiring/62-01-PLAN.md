<objective>
Ship `mix threadline.incident <transaction_id>`, a no-LiveView operator path to answer "what happened in this transaction" directly from the console.

Purpose: Allow SSH-only operators to query transaction incidents without needing the LiveDashboard UI, and enable advanced piping via `--json` output.
Output: A new Mix task that prints human-readable or JSON-encoded `Threadline.incident_bundle/2` output.
</objective>

    2. Start app silently (`Mix.Task.run("app.config", [])`, start `:ssl`, `:postgrex`, `:ecto_sql`).
