Line numbers moved in Plan 03, so always use this live output and never the RESEARCH line numbers.

Fix forms:
- **MapJoin:** `Enum.map_join/3`.
- **FilterFilter / RejectReject:** merge the predicates into one pass.
- **ExpensiveEmptyEnumCheck:** `Enum.empty?/1` or `== []`.
- **NegatedConditionsWithElse:** swap the branches.
- **UnlessWithElse:** `if` with the branches swapped.
- **CondStatements:** a two-branch cond becomes `if`.
- **PreferImplicitTry:** drop the explicit `try` for the function-level implicit form.
- **RedundantWithClauseResult:** return the last clause's expression directly.
- **WithSingleClause:** `case`. Choose a form that does not add a nesting level.
- **ParenthesesOnZeroArityDefs:** drop the `()`.
- **MaxLineLength:** break the line.
- **AliasOrder:** reorder.

After each file, run `mix compile --warnings-as-errors` and that file's tests. Commit template: `refactor(203-04): resolve <Check[, Check]> findings in <path-or-dir>`. Body: "Mechanical Credo sweep: <checks>. No behavior change. Verified: <commands>."
