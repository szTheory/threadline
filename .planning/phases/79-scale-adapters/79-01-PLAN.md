<objective>
Update core configuration and behaviours to support optional enterprise scale-out adapters.

Purpose: We need to prepare `mix.exs` with optional dependencies and extend the core `Threadline.Storage` and `Threadline.ExportQueue` behaviours with an `init/1` callback. This callback will act as a safeguard, ensuring that if an adapter is configured but the underlying library is missing, Threadline raises a clear error at startup instead of crashing randomly at runtime.
Output: Configured `mix.exs` with `optional: true` dependencies, updated behaviour contracts, and updated built-in adapters (`TaskAdapter` and `Local`) with a default `init/1`.
</objective>
