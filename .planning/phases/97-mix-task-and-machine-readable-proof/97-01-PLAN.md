| Boundary | Description |
|----------|-------------|
| CLI caller -> proof task | Untrusted argv must be bounded and validated so invalid filters do not become misleading proof output. |
| Mix task -> evidence proof library | The task must delegate truth shaping to a reusable library layer rather than growing a divergent query model. |
| Proof serializer -> downstream consumers | Wrapped JSON must stay stable so CI wrappers, `jq`, and procurement/audit handoff do not break silently. |
