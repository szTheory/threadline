<interfaces>
Rewrite rules. Apply them only to listed files, under LC_ALL=C with perl `-pi`. Every <NAME> class is ASCII `[A-Za-z0-9._-]+`, and B means "not preceded by `[A-Za-z0-9._-]`". Each rule replaces only the home segment. The rest of the line is untouched.
- R1 B `/Users/<NAME>` becomes `/Users/<user>`
- R2 B `/home/<NAME>` becomes `/home/<user>`, except where <NAME> is `runner` (allowlisted runner account)
- R3 B `~/` followed by a name byte becomes `<home>/`, except where the remainder starts with an allowlisted literal (`.cache`, `.hex`, `.claude/gsd-core/`, `.claude/get-shit-done/`, `.claude/skills/`; derive the exact set from `.github/repo-hygiene-allowlist.tsv` at run time)
- R4 B optional `/private` + `/var/folders/<XX>/<YYYY>/T/` (one or more trailing slashes) becomes `<tmpdir>/`; any other family-5 hit becomes `<tmpdir>`
- R5 `-Users-<NAME>-` becomes `-Users-<user>-`
- R6 JSON-escaped backslash-slash `Users` or `home` backslash-slash <NAME> becomes the same prefix + `<user>`
- R7 Windows drive, colon, backslashes, `Users`, backslashes, <NAME>: <NAME> becomes `<user>`
Placeholders contain `<` and `>`, which the name class excludes. That makes a second pass a no-op, and the guard never flags them.
</interfaces>
</context>
