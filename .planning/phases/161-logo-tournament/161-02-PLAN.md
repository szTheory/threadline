## LOOP PROTOCOL (executed by the orchestrator with the user — round count unknowable, cap 4)

This phase's task list models ONE round-iteration plus the terminal paths. The orchestrator repeats the iteration (checkpoint → transcribe → generate next round) until a winner is declared or the cap decision resolves. Executor agents are dispatched per round-generation only; every human gate runs in the main session.

For each round N (starting at 1):
(a) Orchestrator tells the user to open `.planning/phases/161-logo-tournament/candidates/round-N/gallery.html` in a browser (file://) and collects PER-CANDIDATE verdicts via AskUserQuestion/conversation: one of ADVANCE / KILL / MUTATE plus verbatim reasons for each candidate. "All fine", "looks good", or any blanket response is NOT a verdict — follow up until every candidate has an individual tag and reason. A winner declaration may happen at any round's checkpoint ("CN is the winner" or equivalent explicit statement).
(b) Verdicts and reasons are transcribed VERBATIM (user's words, quoted, not paraphrased) into the round-N Feedback section of ROUNDS.md and committed.
(c) If no winner declared and N < 4: dispatch round-N+1 generation (Task 2 below) — 4-6 candidates, ALL mutations of ADVANCEd/MUTATEd candidates traceable to recorded feedback, max one user-invited wildcard (only if the user asked for one at the checkpoint), same HC gate, same six-context gallery, ROUNDS.md roster section for round N+1. Then repeat from (a) with N+1.
(d) If no winner declared and N = 4: the round cap triggers Task 4's explicit decision checkpoint — extend the tournament or pick the best available. Never silently continue.
(e) On a winner declaration: Task 5 records it and closes the phase.

HARD RULES (every iteration):
- Nothing written under `brandbook/` or `lib/`. Losing candidates never leave the phase dir — graduation to brandbook/ is Phase 162's job, winner only.
- Never touch or stage the pre-existing uncommitted changes under `lib/`, `examples/`, `test/` — stage phase-dir paths explicitly, always.
- Claude NEVER pre-fills, paraphrases, summarizes-in-place, or "tidies" user verdicts. Verbatim means verbatim.
- Every verify gate mechanical.
