## STRIDE Threat Register

| T-175-06 | Tampering (XSS) | Breadcrumb labels derived from URL params (table name, actor id, short-id) | mitigate | Labels render through HEEx `~H`/`render_slot` which auto-escapes; never `raw/1`. | T-175-07 | Spoofing | Wrong breadcrumb trail misrepresents location/hierarchy | mitigate | Explicit `breadcrumbs` assign per D-14 (not route-inferred); standalone vs transaction-scoped row history branch prevents a fabricated transaction parent (D-12). |
| T-175-SC | Tampering | npm/Hex/cargo installs | accept | No installs; zero new runtime deps invariant. No package legitimacy gate needed. |
