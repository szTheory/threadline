## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local repository → `origin` on GitHub | The push publishes local history, including `.planning/`, to a public remote. Crossing it is a human decision, not an agent one. |
| GitHub Actions run → project requirement status | A run's conclusions become the evidence on which two requirements are marked Complete or Pending; a misread or a selectively-retried run becomes a false project fact. |
| Branch-protection ruleset → merge gate | `CI required` is the single required context; narrowing what it aggregates would silently reduce what the merge gate proves. |
