## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-198-04-01 | Tampering | the zero-skips guard | high | mitigate | A literal skip-tag string in the guard's own source would make it self-invalidating (the file matches its own glob). Mitigated by building the needle via runtime concatenation, with an acceptance criterion greping the guard file for the literal and requiring zero. |
| T-198-04-02 | Spoofing | rewritten shape assertions | high | mitigate | A loosened assertion that passes against anything is a false gate. D-05 binds every rewrite to a demonstrated failure against a deliberately drifted source of truth, recorded in the SUMMARY and the triage evidence cell. |
| T-198-04-03 | Information Disclosure | tripwire SQL | low | accept | The query reads only `information_schema.tables` for three fixed table names in schema `public`; the table names are constants, not interpolated input, so there is no injection surface. |
| T-198-04-04 | Elevation of Privilege | `@ui_form_policy` has-forms escape hatch | medium | mitigate | The has-forms value is an unconditional pass, so it could be used to exempt a page. Mitigated by requiring a reason string in the tuple and by keeping the declaration co-located in the page file, so the exemption appears in the same diff as the change and is reviewable. |
| T-198-04-05 | Tampering | `mix test.reset` | medium | accept | The alias drops a database. It is scoped explicitly to `Threadline.Test.Repo` rather than all repos, and the name states the destructive intent. |
