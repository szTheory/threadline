<objective>
Close Gap 5 by measuring, not by asserting. GREEN-07 requires that `origin` carries the work and
that its latest CI run concludes `success` in <= 20 minutes. This plan pushes the gap-closure
round, watches the run to completion, and writes down exactly what happened — including if what
happened is another red.

Purpose: this phase's entire pathology has been claims outrunning evidence. Local `mix test` at
1398/0 was real and did not mean CI green; the first gap-closure round fixed 2 of 7 red jobs while
reading as though it had fixed them all. This plan exists to make the closing claim a measurement
with a run ID attached, and to make a still-red outcome an equally acceptable, equally well-recorded
result.

Output: a run ID, a per-check table, a three-way job comparison against runs 33138291361 and
33183920952, and requirement statuses that match it.

**Hard constraints.** A direct `git push origin main` is refused by the repository ruleset
("Changes must be made through a pull request") — that is GREEN-08's branch protection working as
designed, not an obstacle to route around. Work lands on a `ci/<phase>-<slug>` branch plus a pull
request; PR #29 (`ci/198-gap-closure`) is already open carrying this work. **Never** modify branch
protection, the ruleset, `enforcement`, or `bypass_actors`, and never add a bypass actor.
</objective>
