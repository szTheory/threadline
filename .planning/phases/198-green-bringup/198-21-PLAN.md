merge gate's guarantee self-guarding so it can never again be narrowed silently.

required context, `CI required`. That means a lane can be dropped from
`ci-required`'s `needs:` list and the protection contract stays byte-identical
while the guarantee behind it shrinks. Branch protection structurally cannot detect
this. A contract test can, and this plan builds it — whichever way the decision
went, because the guard's value is prospective.

executable merge-gate contracts.
