<objective>
Close Gap 1: port `test/threadline/pgbouncer_topology_test.exs` to
`Threadline.StorageSchemaCase.repo_opts/0`, and replace the methodology that let it hide with a
**static** sweep that cannot be blind to a tag-excluded file.

Purpose: CI run 33183920952's `PgBouncer transaction topology` job fails at
`pgbouncer_topology_test.exs:21` with `Postgrex.Error 42P01 (undefined_table) relation
"audit_changes" does not exist` — the exact defect class GREEN-04 exists to retire, in a file
198-12's 14-file sweep could not see. The file carries `@moduletag :pgbouncer_topology` (line 16)
and `test/test_helper.exs:6` excludes that tag from every local run, so it never appeared in the
observed local failure list that drove 198-12's file selection.

**The structural lesson is the deliverable, not just the one-file fix.** Porting this file alone
repeats 198-12's mistake at smaller scale: the next environment-gated test to acquire an
unprefixed audit read would be invisible again. This plan therefore also lands a source-level
contract test that scans every file under `test/`, regardless of whether that file runs in the
default suite, so the claim "no unprefixed audit call sites remain" becomes provable rather than
observed.

Output: a green topology test, a run-independent sweep with demonstrated teeth, and no new
exclusion, skip tag, deleted test, or weakened assertion.

**D-02 is binding and non-negotiable.** No schema search parameter on `threadline_test`, no
repo-level default prefix, no `Ecto.Repo` `default_options/1` callback, no hardcoded
storage-schema string literal at a call site. The sanctioned fix is `repo_opts()` as the trailing
opts argument, exactly as 198-08 proved and 198-12 applied to 14 files.
</objective>
