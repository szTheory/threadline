| local git → public origin | First push of the 587 commits happens in this plan |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-198-03-01 | Elevation of Privilege | `ci-required` aggregate gate | high | mitigate | The single-required-check design collapses twelve signals into one; a false-green aggregate would let anything merge. Mitigated by `if: always()` plus full needs-context inspection (D-09), an asserted twelve-entry `needs:` list, and an acceptance criterion that no result-containment expression exists in the file. |
| T-198-03-02 | Tampering | `re-actors/alls-green@release/v1` | medium | accept | The action is referenced by a moving release tag rather than a pinned SHA, so an upstream compromise would execute in CI. Accepted for now: the action's whole body is a result-aggregation decision with no repository write scope, `permissions: contents: read` is set workflow-wide, and pinning is recorded as a follow-up rather than silently ignored. |
