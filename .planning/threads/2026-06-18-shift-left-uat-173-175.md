  Pattern file: `examples/threadline_phoenix/e2e/tests/operator-phase-177-uat.spec.ts`.
  Helpers to reuse: `login`, `expectNoHorizontalOverflow`, `expectBoxWithinViewport`,
  `transitionDuration` + reduced-motion lanes (see also `operator-motion.spec.ts`,
  `operator-responsive-mobile-first.spec.ts`). Stress route: `/audit/__stress?story=<id>`
  (`getByTestId("stress-preview")`, theme from the lane). Light lane = add the spec to
  `playwright.config.ts` `desktop-chromium-light` `testMatch` **array** (keep the existing
  regex element verbatim — `operator-stress.spec.ts` asserts its substring).
  Local targeted run alias: `mix verify.phase177_uat` (mirror it for new specs if useful).
- **Boundary (intentional):** subjective "gap rhythm / coherent unit" is covered by
