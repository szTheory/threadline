Three rules

  1. The name is Threadline: one word, capital T. In code it is threadline.
  2. Never run the thread through the word, and never put a shape behind the spool.
  3. Insert, Update, Delete and Redacted are always written out. Their semantic colors back up the word; they never replace it.

Name. Threadline in running text; threadline in code. The logo is the spool and the word together, with no shape behind it and no tagline.

Where it shows. Full brand on Threadline’s own surfaces; the lockup and semantic colors in Threadline Admin, for the host app’s own team; never shown to the host app’s customers.
